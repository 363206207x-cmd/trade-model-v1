# P329 SourceTraceNumericSourceReadModelValidator Java Skeleton

## Purpose

P329 belongs to the Readiness / Point Mainline.

P329 follows P328 `SOURCETRACE_NUMERIC_SOURCE_CONTEXT_DTO_JAVA_SKELETON`.

P329 adds a minimal plain Java validator skeleton for `SourceTraceNumericSourceContextDTO` and targeted validator tests.

The validator checks source-owned, review-only, incomplete-safe, fail-closed, and not-trade-instruction boundaries for the SourceTrace numeric source read model.

P329 is not an assembler, not service wiring, not RuntimeKlineContext wiring, not dashboard runtime integration, not external push, and not order / execution / auto-trading.

## Added Java Boundary

P329 adds only:

- `src/main/java/org/example/trademodel/validator/point/SourceTraceNumericSourceReadModelValidator.java`;
- `src/test/java/org/example/trademodel/validator/point/SourceTraceNumericSourceReadModelValidatorTest.java`.

The validator accepts only `SourceTraceNumericSourceContextDTO`.

The validator returns:

- `INCOMPLETE`;
- `BLOCKED_FAIL_CLOSED`;
- `REVIEW_ONLY_SOURCE_TRACE`;
- `REVIEW_ONLY_SOURCE_TRACE_DEGRADED`.

The result remains:

- `reviewOnly = true`;
- `notTradeInstruction = true`;
- `manualReviewRequired = true`.

These statuses are not executable trade instructions.

## Safety Checks

The validator checks:

- `reviewOnly`;
- `notTradeInstruction`;
- `manualReviewRequired`;
- `incompleteSafe`;
- `failClosed` for blocked contexts;
- required missing / blocked reasons;
- required SourceTrace identity fields;
- allowed source-owned source types;
- forbidden source types;
- trusted-source state;
- freshness;
- downstream context refs as references only;
- numeric field role requirements;
- forbidden executable semantics.

Any safety flag false is `BLOCKED_FAIL_CLOSED`.

Any forbidden source type is `BLOCKED_FAIL_CLOSED`.

Any forbidden executable semantic in public status / reason / source strings is `BLOCKED_FAIL_CLOSED`.

Stale, unknown, missing, or incomplete required fields remain `INCOMPLETE`.

## Numeric Boundary

P329 does not calculate numeric values.

P329 does not infer numeric values from:

- latest price;
- latest close;
- score / label;
- AI prose;
- dashboard text;
- order book direct reads;
- external provider direct reads.

For `REVIEW_ONLY_SOURCE_TRACE`, point-value roles require explicit `numericValue`.

Zone roles require an explicit numeric value or zone value.

`SOURCE_ONLY_REFERENCE` may remain without numeric values when refs are present.

All numeric fields remain review-only and not trade instructions.

## Source Type Boundary

Allowed source-owned source types remain:

- `STRUCTURE_LEVEL`;
- `INVALIDATION_LEVEL`;
- `LIQUIDITY_POOL_LEVEL`;
- `PRIOR_HIGH_LOW_LEVEL`;
- `VWAP_OR_VOLUME_LEVEL`;
- `ATR_REFERENCE_LEVEL`;
- `MULTITIMEFRAME_CONFIRMATION_LEVEL`;
- `RISK_ACTION_GUARD_REFERENCE`;
- `MANUAL_REVIEW_SOURCE`.

Forbidden source types are fail-closed:

- `AI_PROSE_ONLY`;
- `DASHBOARD_TEXT_ONLY`;
- `SCORE_LABEL_ONLY`;
- `FINAL_DECISION_TEXT_ONLY`;
- `LATEST_PRICE_ONLY`;
- `LATEST_CLOSE_ONLY`;
- `HARDCODED_DEFAULT`;
- `MANUALLY_INVENTED_FALLBACK`;
- `DISPLAY_SLOT_ONLY`;
- `ORDER_BOOK_DIRECT`;
- `EXTERNAL_PROVIDER_DIRECT`;
- `ORDER_EXECUTION_PATH`;
- `AUTO_TRADING_PATH`.

These checks do not authorize source context runtime reads.

## Test Coverage

The targeted test verifies:

- null context is safely incomplete;
- incomplete and blocked statuses require safe reasons;
- complete allowed source returns review-only source trace;
- degraded source trace requires missing reason;
- required SourceTrace identity fields are checked;
- stale / unknown / null freshness is incomplete;
- every forbidden source type is blocked fail-closed;
- entry / stop / TP / RR value roles require explicit numeric values;
- `SOURCE_ONLY_REFERENCE` can pass without numeric values when refs exist;
- forbidden executable semantics are blocked;
- safety flag false and untrusted source fail closed;
- normal validator result outputs do not contain executable semantics;
- the validator has no Spring annotations;
- the validator has no assembler, service, controller, mapper, repository, scheduler, market client, HTTP client, data source, external push, order, execution, or auto-trading class dependency.
