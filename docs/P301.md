# P301 Candidate Preview / Ranking Guard Review-Only Slice

P301 belongs to the Candidate / Push Mainline.

P301 continues from P300's review-only candidate attention and adds a review-only candidate preview / ranking guard skeleton.

This package turns `ReviewOnlyCandidateAttentionDTO` into `ReviewOnlyCandidatePreviewGuardDTO` through a small assembler. The output remains review-only, not a trade instruction, and manual-review required.

P301 is not a real Candidate implementation.

P301 does not generate candidate rank or candidate score.

P301 does not generate a real ranking result.

P301 does not generate Promote To Home.

P301 does not generate Opportunity Push.

P301 does not generate Readiness.

P301 does not generate point generation, entry, stop, TP, or RR.

P301 does not connect `MarketQuoteClient` or `BinanceMarketQuoteClient`.

P301 does not read runtime, live, or external market data.

The user value is that review-only candidate attention can now move into a safe candidate preview / ranking guard object for later internal push preview / recheck handoff work instead of stopping at candidate attention.
