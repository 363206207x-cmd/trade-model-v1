# P331 SourceTraceNumericSourceReadModelAssembler Java Skeleton

## Purpose

P331 belongs to the Readiness / Point Mainline.

P331 follows P330 `SOURCETRACE_NUMERIC_SOURCE_VALIDATOR_VERIFICATION`.

P331 adds a minimal Java assembler skeleton for the SourceTrace numeric source read model:

- `SourceTraceNumericSourceReadModelAssembler`;
- `SourceTraceNumericSourceReadModelAssemblerTest`.

The assembler converts explicit `AssemblyInput` fields into `SourceTraceNumericSourceContextDTO`, immediately calls `SourceTraceNumericSourceReadModelValidator`, and returns the DTO plus validation result.

## Scope

P331 is a Java/test assembler skeleton package.

It is:

- assembler-only;
- targeted-test-only;
- plain Java;
- source-owned read-model carrier assembly only;
- mandatory validator gated.

It is not:

- a SourceTrace runtime read;
- a RuntimeKlineContext integration;
- a DataQualityContext integration;
- a MultiTimeframeContext integration;
- a RiskActionGuardContext integration;
- a service;
- a controller / mapper / repository / scheduler;
- a dashboard runtime package;
- an external channel package;
- order / execution / auto-trading.

## Assembler Boundary

`SourceTraceNumericSourceReadModelAssembler` may only move explicit input fields into a DTO:

- `sourceTraceId`;
- `sourceOwner`;
- `sourceType`;
- `sourceContractId`;
- `symbol`;
- `market`;
- `timeframe`;
- `numericFieldName`;
- `numericFieldRole`;
- `numericValue`;
- `numericValueLow`;
- `numericValueHigh`;

- `dataQualityContextRef`;
- `multiTimeframeContextRef`;
- `riskActionGuardRef`;
- `missingReason`;
- `blockedReason`;
- `requestedStatus`.

The assembler must not calculate or infer any numeric field.

## Assembly Behavior

P331 defines the following skeleton behavior:

- `null` input becomes `INCOMPLETE`;
- `BLOCKED_FAIL_CLOSED` input calls `SourceTraceNumericSourceContextDTO.blockedFailClosed(...)`;
- `REVIEW_ONLY_SOURCE_TRACE_DEGRADED` input calls `SourceTraceNumericSourceContextDTO.degraded(...)`;
- `REVIEW_ONLY_SOURCE_TRACE` input calls `SourceTraceNumericSourceContextDTO.reviewOnly(...)`;
- `INCOMPLETE` or unsupported input calls `SourceTraceNumericSourceContextDTO.incomplete(...)`;
- every assembled DTO is passed to `SourceTraceNumericSourceReadModelValidator.validate(...)`;
- the return object contains both `context` and `validationResult`.

## Explicit Non-Generation Rules

P331 does not:

- calculate `numericValue`;
- calculate entry;
- calculate stop;
- calculate TP;
- calculate RR;
- derive entry from latest price;
- derive boundaries from latest close;
- derive stop from volatility or ATR;

- derive fields from score / label / AI prose / dashboard text;
- create default numeric values;
- create final direction;
- create a trading action.

## Source Type Handling

The assembler only carries `sourceType`.

Allowed source types remain source-owned evidence only:

- `STRUCTURE_LEVEL`;
- `INVALIDATION_LEVEL`;
- `LIQUIDITY_POOL_LEVEL`;
- `PRIOR_HIGH_LOW_LEVEL`;
- `VWAP_OR_VOLUME_LEVEL`;
- `ATR_REFERENCE_LEVEL`;
- `MULTITIMEFRAME_CONFIRMATION_LEVEL`;
- `RISK_ACTION_GUARD_REFERENCE`;
- `MANUAL_REVIEW_SOURCE`.

- `AI_PROSE_ONLY`;
- `DASHBOARD_TEXT_ONLY`;
- `SCORE_LABEL_ONLY`;
- `FINAL_DECISION_TEXT_ONLY`;
