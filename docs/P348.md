# P348 SourceOwnedCandidateIntegrationSourceBindingAssembler Plan

P348 is an A-risk docs-only assembler plan in the Readiness / Point Mainline.

It designs the future `SourceOwnedCandidateIntegrationSourceBindingAssembler`.

## Future Assembler Position

Future Source-Owned Candidate Integration Source Binding Assembler sits after explicit source binding inputs and before any future source-owned candidate integration validation result is consumed by later review-only candidate work.

The future chain remains:

`SourceTrace + RuntimeKlineContext + DataQualityContext + MultiTimeframeContext + RiskActionGuard + WatchlistPoolProof -> SourceOwnedCandidateIntegrationSourceBindingDTO -> SourceOwnedCandidateIntegrationSourceBindingValidator -> future source-owned candidate integration consumer`

The assembler may only move explicit input fields into the DTO and invoke the validator.

It must not read runtime providers, database state, service state, dashboard text, latest price, latest close, Watchlist service, rule config, audit tables, or external channels.

Future assembler may only:

- preserve review-only safety flags;

## DTO Factory Selection Rules

Future assembler should select DTO factories by explicit `requestedStatus` or explicit missing / blocked state only:

- input is null -> DTO `incomplete(...)`;
- `requestedStatus = INCOMPLETE` -> DTO `incomplete(...)`;
- `requestedStatus = BLOCKED_FAIL_CLOSED` -> DTO `blockedFailClosed(...)`;
- `requestedStatus = REVIEW_ONLY_SOURCE_OWNED_CANDIDATE_INTEGRATION_BINDING_DEGRADED` -> DTO `degraded(...)`;
- `requestedStatus = REVIEW_ONLY_SOURCE_OWNED_CANDIDATE_INTEGRATION_BINDING` -> DTO `reviewOnly(...)`;
- unsupported status -> DTO `incomplete(...)`.

Future assembler must not calculate status.

Future assembler must not infer trade direction.

Future assembler must not promote degraded or incomplete input to review-only success.

Future assembler must not replace a missing reason or blocked reason with executable language.

## Validator Invocation Rules

Future assembler must:

- build the DTO first;
- immediately call `SourceOwnedCandidateIntegrationSourceBindingValidator.validate(...)`;
- return validator `ValidationResult` without dropping reasons;
- default to `new SourceOwnedCandidateIntegrationSourceBindingValidator()`;
- allow test injection of a validator only to verify invocation.

Future assembler must not:

- bypass the validator;
- swallow validation reasons;
- modify DTO after validation failure to make it pass;
- downgrade `BLOCKED_FAIL_CLOSED` to review-only success;
- upgrade `INCOMPLETE` to review-only success;
- treat validator success as runtime candidate availability.

## Incomplete-Safe Assembly Rules

Future assembler must preserve `INCOMPLETE` when any of the following appears:

- input is null;
- required refs are missing;
- `sourceBindingCompletenessScore` is missing;
- `allRequiredSourcesPresent=false`;
- `anySourceIncomplete=true`;
- required `missingReason` is absent;
- only latest price exists;
- only latest close exists;
- only dashboard text exists;
- only AI prose exists.

Incomplete output remains review-only, manual-review required, and not a trade instruction.

It must not become usable candidate output.

## Fail-Closed Assembly Rules

Future assembler must preserve `BLOCKED_FAIL_CLOSED` when any of the following appears:

- `allRequiredSourcesTrusted=false`;
- `allRequiredSourcesReviewOnly=false`;
- `allRequiredSourcesNotTradeInstruction=false`;
- `allRequiredSourcesManualReviewRequired=false`;
- `allRequiredSourcesIncompleteSafe=false`;
- `anySourceBlocked=true`;
- RiskActionGuard blocked;
- RiskActionGuard stampede;
- RiskActionGuard wick-only reverse semantics;
- RiskActionGuard liquidity-degraded one-shot exit semantics;
- WatchlistPoolProof disabled;
- WatchlistPoolProof empty;
- WatchlistPoolProof non-member;
- WatchlistPoolProof untrusted;
- Display Slots / default six home assets are treated as Watchlist Pool Proof;
- external channel semantics appear;
- Push send semantics appear;
- order semantics appear;
- execution semantics appear;
- auto-trading semantics appear.

Fail-closed output must not produce usable candidate output.

It must not generate point values, final direction, push payload, or trade actions.

P348 reconfirms:

- high risk does not mean immediate stop;
- high risk does not mean immediate reverse;
