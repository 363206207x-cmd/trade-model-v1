# P291H GitHub-Native Workflow Simplification Pack

P291H is a workflow simplification and GitHub hygiene pack.

It does not advance business-chain functionality.

The goal is to move the default process from terminal-script-first to GitHub-native-first:

- GPT decides the next pack.
- Codex executes the scoped task and creates the Issue, branch, and Draft PR.
- GPT reviews the GitHub PR.
- The user only confirms B/C or C merges.
- Terminal scripts remain fallback tools and local sync helpers.

P291H also documents stale PR / Issue hygiene so old open PRs and Issues do not pollute current-task detection.

This package does not change Market Read, Evidence, Score, Candidate, Push, Readiness, point generation, execution advice, order APIs, execution APIs, or auto-trading.
