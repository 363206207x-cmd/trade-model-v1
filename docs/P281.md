# P281 RealScanInputContractGuardValidator Skeleton

P281 adds a Java skeleton plus targeted test for `RealScanInputContractGuardValidator`.

P280 merged as `bd1bfeb` (`BACKEND-P280 Real Scan Input Contract DTO Closure and Guard Validator Authorization Scope Pack (#679)`). P281 follows that authorization gate and remains limited to validating `RealScanInputContractDTO` safety, Watchlist Pool proof, fail-closed states, review-only flags, `manualReviewRequired=true`, and `notTradeInstruction=true`.

## Scope

P281 adds:

- `RealScanInputContractGuardValidator`
- `DefaultRealScanInputContractGuardValidator`
- `DefaultRealScanInputContractGuardValidatorTest`
- `PHASE_P281_REAL_SCAN_INPUT_CONTRACT_GUARD_VALIDATOR_SKELETON_VERIFICATION.md`

The validator is a plain Java skeleton. It has no Spring annotations and no service wiring.

## Validator Semantics

The validator may only validate:

- DTO safety defaults.
- Watchlist Pool proof.
- Fail-closed states.
- Review-only flags.
- Manual review / not-trade-instruction invariants.

Null input fails closed.

Missing Watchlist Pool proof remains fail-closed.

Non-watchlist input remains fail-closed.

Blocked input cannot be upgraded to `REVIEW_ONLY`.

Valid-looking input remains review-only and not trade instruction.
