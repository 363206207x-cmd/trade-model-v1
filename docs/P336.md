## Safety Flags / 安全标记

All factories force:

- `reviewOnly = true`;
- `notTradeInstruction = true`;
- `manualReviewRequired = true`;
- `incompleteSafe = true`.

所有 factory 强制：

- `reviewOnly = true`；
- `notTradeInstruction = true`；
- `manualReviewRequired = true`；
- `incompleteSafe = true`。

`blockedFailClosed(...)` forces `failClosed = true` and requires a non-blank blocked reason.

`blockedFailClosed(...)` 强制 `failClosed = true` 且要求 blocked reason 非空。

`incomplete(...)` and `degraded(...)` require non-blank missing reasons.

`incomplete(...)` 和 `degraded(...)` 要求 missing reason 非空。

No factory, setter, or builder can disable safety flags.

任何 factory、setter 或 builder 都不能关闭 safety flags。
