# P345 SourceOwnedCandidateIntegrationSourceBindingDTO Java Skeleton

## Package Type

P345 is a B-risk Java/test DTO skeleton package in the Readiness / Point Mainline.

It follows P343 Source-Owned Candidate Integration Boundary Plan and P344 Source-Owned Candidate Integration Source Binding Plan.

P345 adds only the L1 DTO carrier for future Source-Owned Candidate Integration Source Binding.

## DTO Boundary

`SourceOwnedCandidateIntegrationSourceBindingDTO` is a plain Java carrier.

It may carry explicit fields such as:

- candidate integration context id;
- symbol / market / primary timeframe;
- SourceTrace refs;
- RuntimeKlineContext / DataQualityContext / MultiTimeframeContext / RiskActionGuard / WatchlistPoolProof refs;
- upstream source binding statuses;
- source binding completeness score;
- upstream safety summaries;
- candidate boundary / unavailable / blocked / degraded labels;
- source-owned trace refs;
- missing / degraded / blocked reasons;
- observed / created timestamps;
- safety flags.

The DTO does not validate these fields.

The DTO does not assemble source-owned candidates.

The DTO does not read runtime, DB, service, market data, latest price, latest close, dashboard text, Watchlist service, or external providers.

## Status Values

The DTO status enum is:

- `INCOMPLETE`;
- `BLOCKED_FAIL_CLOSED`;
- `REVIEW_ONLY_SOURCE_OWNED_CANDIDATE_INTEGRATION_BINDING`;
- `REVIEW_ONLY_SOURCE_OWNED_CANDIDATE_INTEGRATION_BINDING_DEGRADED`.

These statuses are source binding DTO statuses only.

They are not candidate generation statuses, final direction statuses, push statuses, or trading statuses.

## Factory Rules

The DTO exposes only static factories:

- `incomplete(...)`;
- `blockedFailClosed(...)`;
- `degraded(...)`;
- `reviewOnly(...)`.

All factories force:

- `reviewOnly=true`;
- `notTradeInstruction=true`;
- `manualReviewRequired=true`;
- `incompleteSafe=true`.

`failClosed` is true only for `BLOCKED_FAIL_CLOSED`.

No constructor, setter, builder, or factory parameter can turn off safety flags.

List fields are defensively copied and exposed as immutable lists.
