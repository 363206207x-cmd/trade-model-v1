# P258 Opportunity Push Review-Only Skeleton

## 1. 阶段定位

P258 完成 Opportunity Push review-only DTO / enum / rule skeleton。

P258 只表达“值得人工关注的机会提醒候选”，不是外部推送执行，不是交易指令，不是 readiness，不是 point generation。

## 2. 本轮新增内容

- `OpportunityPushDTO`
- `OpportunityPushStatusEnum`
- `OpportunityPushRule`
- `DefaultOpportunityPushRule`
- `DefaultOpportunityPushRuleTest`
- `PHASE_P258_OPPORTUNITY_PUSH_REVIEW_ONLY_SKELETON_VERIFICATION.md`

## 3. 安全语义

- 所有输出必须保持 review-only / fail-closed。
- `manualReviewRequired=true` 必须保留。
- `notTradeInstruction=true` 必须保留。
- `externalPushSent=false` 必须保留。
- `readinessUpgraded=false` 必须保留。
- `tradingActionCreated=false` 必须保留。
- `entryStopTpRrGenerated=false` 必须保留。
- Risk Action Guard blocker / stampede / liquidity deterioration 必须阻断 push eligibility。
- wick-only / pin-bar direct reversal reason 不得变成趋势反转推送。

## 4. 本轮未做

- 不实现 external Opportunity Push execution。
- 不发送 Telegram / email / webhook / app notification。
- 不接 API / dashboard / scheduler。
- 不接 MarketQuoteClient / BinanceMarketQuoteClient。
- 不读取 runtime / live / external data。
- 不实现 Readiness。
- 不实现 point generation。
- 不生成 entry / stop / TP / RR。
- 不接 order API / execution API / auto-trading。

## 5. 结论

P258 是最大安全 review-only Opportunity Push skeleton。

P258 不是外部推送，不是 readiness，不是交易动作。
