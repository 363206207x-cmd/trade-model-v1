# P304 Dashboard / Internal Push Preview Display Gate

P304 belongs to the Candidate / Push Mainline（候选 / 推送主线）.

P304 continues from P303, where the internal push preview was closed before any external channel.

P304 adds a dashboard / internal display gate for the review-only internal push preview. It is a read-only display surface and is not a real Push.

P304 does not connect Telegram, email, webhook, app notification, local notification, or any external channel.

P304 does not generate external channel messages, sendable messages, Readiness, point generation, entry, stop, TP, RR, order intent, execution intent, or auto-trading behavior.

P304 must show that `recheckRequired = true` and `riskActionGuardRequired = true`.

User value: P304 lets the user see on the dashboard that the system is preparing an internal push preview path, while clearly showing that it remains review-only, manual-review required, not a trade instruction, and unable to send.
