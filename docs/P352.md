# P352 Source-Owned Candidate Integration Runtime Input Contract Plan

## Package Type

P352 is an A-risk docs-only runtime input contract plan in the Readiness / Point Mainline.

It refines the P351 runtime boundary into an explicit input contract for any future Source-Owned Candidate Integration runtime candidate generation work.

P352 adds no Java, no tests, no runtime wiring, no service, no dashboard, no external channel, no Push send, no order, no execution, and no auto-trading.

## Capability Movement

`SOURCE_OWNED_CANDIDATE_INTEGRATION_RUNTIME_BOUNDARY_PLAN -> SOURCE_OWNED_CANDIDATE_INTEGRATION_RUNTIME_INPUT_CONTRACT_PLAN`

This movement plans the runtime input contract only.

It does not make a runtime DTO available.

It does not make runtime candidate generation, point generation, final direction, push sending, or trading available.

## Runtime Input Contract Principle

Future runtime input must come from explicit source binding results.

Runtime candidate generation must not read or infer inputs by itself.

Allowed input sources are limited to:

- SourceTrace source binding result;
- RuntimeKlineContext source binding result;
- DataQualityContext source binding result;
- MultiTimeframeContext source binding result;
- RiskActionGuard source binding result;
- WatchlistPoolProof source binding result;
- SourceOwnedCandidateIntegrationSourceBinding assembled result / validation result.

Runtime candidate generation must not read:

- market data provider;
- latest price;
- latest close;
- dashboard text;
- AI prose;
- Watchlist service;
- rule config;
- audit table;
- account state;
- position state;
- order state;
- external channel state;
- push channel state.

## Watchlist Pool Boundary

Watchlist Pool is the maximum boundary for candidate / opportunity push eligibility.

Display Slots and default home assets are not Watchlist Pool Proof.

Default display does not mean push is allowed.

Assets outside the Watchlist Pool must not enter candidates.

P352 does not connect Watchlist service, read rule config, or read audit table.

## Risk Action Guard Boundary

High risk does not mean immediate stop, reverse, or open.

Strong reversal does not mean direct reverse.

Wick-only does not mean trend reversal.

Stampede state blocks opportunity push, reverse, and new open semantics.

Liquidity degradation must not become one-shot market exit semantics.

P352 does not generate executable risk actions.
