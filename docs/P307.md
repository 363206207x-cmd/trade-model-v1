# P307 Review-only Readiness Gate Skeleton

P307 belongs to the Readiness / Point Mainline（就绪 / 点位主线）.

P307 continues from the P306 readiness / point boundary plan.

P307 adds a review-only readiness gate skeleton:

- `ReviewOnlyReadinessGateDTO`
- `ReviewOnlyReadinessGateAssembler`
- targeted tests for review-only flags, fail-closed behavior, source preservation, Risk Action Guard preservation, and forbidden point / execution / external-channel surfaces

P307 turns `ReviewOnlyInternalPushPreviewDTO` into a readiness gate output that can only support manual review.

P307 is not real readiness.

P307 does not create executable readiness.

P307 does not generate point output.

P307 does not generate entry, stop, TP, or RR.

P307 does not connect external channels.

P307 does not send Telegram, email, webhook, app notification, local notification, or any message.

P307 does not create order intent, execution intent, order API, execution API, or auto-trading.

P307 preserves:

- `reviewOnly = true`
- `notTradeInstruction = true`
- `manualReviewRequired = true`
- `recheckRequired = true`
- `riskActionGuardRequired = true`
- `blockingReasons`
- `riskBlockers`

User value: P307 lets internal push preview enter a review-only readiness gate so a human can see whether the chain is safe enough to proceed to a later point-boundary review stage, while still blocking point generation, external send, and trading behavior.
