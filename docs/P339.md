## DataQualityContext Binding Boundary

DataQualityContext source binding is a data quality gate between RuntimeKlineContext source binding and future MultiTimeframe / RiskActionGuard checks.

It may carry only explicit input fields:

- SourceTrace refs;
- RuntimeKlineContext ref;
- data quality score;
- data quality grade;
- hard and warning threshold flags;
- SourceTrace completeness score;
- RuntimeKline completeness score;
- OHLCV completeness score;
- freshness score;
- multi-timeframe consistency score;
- missing / degraded / blocked reasons.

It does not calculate score values. It does not read market data. It does not derive point values.
