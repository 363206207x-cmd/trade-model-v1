P335 is a docs-only plan package in the Readiness / Point Mainline.

`RuntimeKlineContext Source Binding` 是未来把 K 线现场证据绑定到已存在 SourceTrace numeric source refs 的方案。

- how latest price / latest close may be carried only as evidence;
- how OHLCV completeness, wick, gap, liquidity, and stampede state affect incomplete-safe or fail-closed outcomes;
- why RuntimeKlineContext cannot directly generate point values.

它可以定义：

- 哪些 runtime evidence 字段是必需的；
- 为什么 SourceTrace refs 必须先存在才能进入 runtime evidence review；
- latest price / latest close 只能如何作为证据被承载；
- OHLCV 完整性、wick、gap、liquidity、stampede 状态如何影响 incomplete-safe 或 fail-closed；
- 为什么 RuntimeKlineContext 不能直接生成点位。

It must not:

- read latest close;

- create RuntimeKlineContext Java DTOs;

- send externally;

- execute;
- auto-trade.

它不得：

- 读取行情；
- 读取 latest price；

- 接外部 provider；
- 创建 RuntimeKlineContext Java DTO；
- 用 Java 校验 runtime data；

## SourceTrace Binding Rules / SourceTrace 绑定规则

RuntimeKlineContext can only bind existing SourceTrace refs:

- entry source trace ref;
- stop source trace ref;
- TP source trace ref;
- RR source trace ref;
- source-only reference trace ref.

RuntimeKlineContext 只能绑定已经存在的 SourceTrace refs：

- entry source trace ref；
- stop source trace ref；
- TP source trace ref；
- RR source trace ref；
- source-only reference trace ref。

Rules:

- missing `sourceTraceRefs` -> `INCOMPLETE`;
- symbol / market / timeframe mismatch -> `INCOMPLETE`;
- stale SourceTrace refs -> `INCOMPLETE`;
- forged or untrusted SourceTrace refs -> `BLOCKED_FAIL_CLOSED`;
- RuntimeKlineContext cannot create `sourceTraceRef`;
- RuntimeKlineContext cannot replace `sourceTraceRef` with latestPrice-only evidence.

规则：

- 缺少 `sourceTraceRefs` -> `INCOMPLETE`；
- symbol / market / timeframe 不一致 -> `INCOMPLETE`；
- SourceTrace refs stale -> `INCOMPLETE`；
- SourceTrace refs forged / untrusted -> `BLOCKED_FAIL_CLOSED`；
- RuntimeKlineContext 不能创建 `sourceTraceRef`；
- RuntimeKlineContext 不能用 latestPrice-only 替代 `sourceTraceRef`。

`latestPrice` and `latestClose` are only scene evidence.

`latestPrice` 与 `latestClose` 只能作为现场证据。

它们不能单独生成点位。

- latestPrice is not entry;
- latestClose is not stop;
- latestPrice is not TP;
- latestPrice cannot generate RR;

规则：

- latestClose-only -> `INCOMPLETE`；
- latestPrice 不等于 entry；
- latestClose 不等于 stop；
- latestPrice 不等于 TP；
- latestPrice 不能生成 RR；
- latestPrice 不能替代 SourceTrace；
- latestPrice 不能绕过 RiskActionGuard。

## OHLCV Completeness Rules / OHLCV 完整性规则

Rules:

- OHLCV missing -> `INCOMPLETE`;
- volume missing -> `INCOMPLETE`;
- candle not closed when a closed candle is required -> `INCOMPLETE`;
- quoteVolume missing when required -> `INCOMPLETE`;
- ohlcvCompleteness below threshold -> `INCOMPLETE`;
- forged OHLCV -> `BLOCKED_FAIL_CLOSED`;
- inconsistent OHLCV -> `BLOCKED_FAIL_CLOSED`;
- severe gap -> `BLOCKED_FAIL_CLOSED`.

规则：

- OHLCV missing -> `INCOMPLETE`；
- volume missing -> `INCOMPLETE`；
- 需要 closed candle 但 candle not closed -> `INCOMPLETE`；
- 需要 quoteVolume 但 quoteVolume missing -> `INCOMPLETE`；
- ohlcvCompleteness below threshold -> `INCOMPLETE`；
- forged OHLCV -> `BLOCKED_FAIL_CLOSED`；
- inconsistent OHLCV -> `BLOCKED_FAIL_CLOSED`；
- severe gap -> `BLOCKED_FAIL_CLOSED`。

## Wick / Gap / Stampede Rules / wick、gap、stampede 规则

Risk action layering must remain:

- wick-only signal -> `INCOMPLETE`;
- wick-only is not trend reversal;
- strong reversal unconfirmed -> `INCOMPLETE`;
- strong reversal is not direct reverse;
- stampede suspected -> `INCOMPLETE` or `BLOCKED_FAIL_CLOSED` depending on severity;
- stampede confirmed -> `BLOCKED_FAIL_CLOSED`;
- liquidity severely degraded with executable output attempted -> `BLOCKED_FAIL_CLOSED`;
- high risk is not immediate stop;
- degraded liquidity does not recommend one-shot market cut.

风险动作分层必须保持：

- wick-only signal -> `INCOMPLETE`；
- wick-only 不能当趋势反转；
- strong reversal unconfirmed -> `INCOMPLETE`；
- strong reversal 不能直接反手；
- stampede suspected -> 根据严重程度进入 `INCOMPLETE` 或 `BLOCKED_FAIL_CLOSED`；
- stampede confirmed -> `BLOCKED_FAIL_CLOSED`；
- liquidity severely degraded 且尝试 executable output -> `BLOCKED_FAIL_CLOSED`；
- 风险高不等于立即止损；
- 流动性恶化不建议一次性市价砍仓。
