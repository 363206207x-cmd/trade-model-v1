# P310 Point Proposal Closure / Dashboard Display Gate

## Purpose

P310 belongs to the Readiness / Point Mainline.

It continues from P309, where `ReviewOnlyPointProposalDTO` and `ReviewOnlyPointProposalAssembler` introduced a source-owned review-only point proposal skeleton.

P310 closes that skeleton as an internal display gate. It proves that point proposal output can become a safe, read-only display object without becoming executable point generation or a trade instruction.

## What P310 Adds

- `ReviewOnlyPointProposalDisplayDTO`
- `ReviewOnlyPointProposalDisplayAssembler`
- targeted display-gate tests

The display gate may show status, reasons, required guards, allowed next step, and a safe display message.

It must not show entry / stop / TP / RR values as executable values. Even if an upstream proposal object carries those fields, P310 maps them to review-only unavailable placeholders.

## What P310 Is Not

P310 is not executable point generation.

P310 does not generate real entry, stop, TP, RR, final direction, long-short signal, order intent, execution intent, or auto-trading.

P310 does not modify `dashboard.html`.

P310 does not add controller, endpoint, API, mapper, repository, scheduler, resource, schema, config, external channel, Telegram, email, webhook, push send, order, or execution integration.

## Preserved Safety Semantics

P310 preserves:

- `reviewOnly = true`
- `notTradeInstruction = true`
- `manualReviewRequired = true`
- `recheckRequired = true`
- `riskActionGuardRequired = true`
- `sourceTraceRequired = true`
- `runtimeKlineContextRequired = true`
- incomplete-safe behavior
- fail-closed behavior when source context is missing
- fail-closed behavior when risk blockers exist

## Display Gate Rules

The display object may output:

- point proposal status
- review-only status
- incomplete reason
- blocked reason
- source trace required
- runtime kline context required
- recheck required
- Risk Action Guard required
- manual review required
- allowed next step
- safe display message

The display object must not render:

- buy / sell / long / short wording;
- open / close / reverse wording;
- order / execute / auto-trade wording;
- entry price, stop loss, take-profit, or RR as executable instructions.

## User Value

P310 makes the P309 point proposal skeleton usable as an internal review-only display object. It gives the dashboard path a safe object shape without touching the dashboard, API, external channel, or execution system.

## Next Boundary

P310 does not authorize the next stage to create executable point values.

Any future executable point generation, external channel, order, execution, or auto-trading path requires a separate plan, approval, PR, and safety review.
