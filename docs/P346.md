It follows:

- P343 Source-Owned Candidate Integration Boundary Plan;
- P344 Source-Owned Candidate Integration Source Binding Plan;

## Validator Boundary

`SourceOwnedCandidateIntegrationSourceBindingValidator` validates only an already-created `SourceOwnedCandidateIntegrationSourceBindingDTO`.

It checks:

- null context;
- missing binding status;
- safety flags;
- required upstream refs;
- source binding completeness score;
- upstream source safety summaries;
- source blocked / incomplete / degraded summaries;
- untrusted source;
- inherited RiskActionGuard and WatchlistPoolProof boundary labels;
- forbidden executable semantics.

The validator does not assemble source-owned candidates.

The validator does not read runtime, DB, service, market data, latest price, latest close, dashboard text, Watchlist service, or external providers.

## Validation Status Values

The validator status enum is:

- `INCOMPLETE`;
- `BLOCKED_FAIL_CLOSED`;
- `REVIEW_ONLY_SOURCE_OWNED_CANDIDATE_INTEGRATION_BINDING`;
- `REVIEW_ONLY_SOURCE_OWNED_CANDIDATE_INTEGRATION_BINDING_DEGRADED`.

These statuses are validation statuses only.

They are not candidate generation statuses, final direction statuses, push statuses, or trading statuses.

## Inherited Boundaries

P346 inherits P343 / P344 boundaries.

The validator keeps source-owned candidate integration blocked when:

- any required upstream source is missing;
- any upstream source is untrusted;
- any upstream safety flag is not review-only / not-trade-instruction / manual-review-required / incomplete-safe;
- any upstream source is blocked;
- RiskActionGuard boundary is blocked;
- RiskActionGuard stampede / wick-only reverse / liquidity-degraded one-shot-exit semantics appear;
- WatchlistPoolProof is disabled / empty / non-member / untrusted;
- WatchlistPoolProof stale status appears;
- Display Slots are treated as Watchlist Pool Proof;
- external channel, Push send, order, execution, or auto-trading semantics appear.
