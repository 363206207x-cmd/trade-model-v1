# P332 SourceTrace Numeric Source Assembler Verification

## Purpose

P332 belongs to the Readiness / Point Mainline.

P332 follows P331 `SOURCETRACE_NUMERIC_SOURCE_READ_MODEL_ASSEMBLER_JAVA_SKELETON`.

P332 is a docs-only verification closure package for the P331 SourceTrace numeric source read-model assembler skeleton.

P332 verifies that P331 only added:

- a plain Java `SourceTraceNumericSourceReadModelAssembler`;
- targeted tests for that assembler;
- explicit input movement into `SourceTraceNumericSourceContextDTO`;
- mandatory `SourceTraceNumericSourceReadModelValidator` validation.

P332 adds no Java, no tests, no runtime wiring, no service, no dashboard, no external channel, and no execution path.

## Capability Movement

`SOURCETRACE_NUMERIC_SOURCE_READ_MODEL_ASSEMBLER_JAVA_SKELETON -> SOURCETRACE_NUMERIC_SOURCE_ASSEMBLER_VERIFICATION`

## P331 Verified Scope

P331 completed only a SourceTrace numeric source read-model assembler skeleton.

The assembler:

- accepts explicit `AssemblyInput` fields;
- moves those fields into `SourceTraceNumericSourceContextDTO`;
- does not calculate or infer numeric values;
- immediately calls `SourceTraceNumericSourceReadModelValidator`;
- returns both `context` and `validationResult`.

The assembler remains plain Java and does not use Spring, Bean Validation, Jackson, Lombok, external dependencies, runtime providers, or service wiring.

## Status Behavior Verified

P332 verifies the P331 status boundary:

- null input remains `INCOMPLETE`;
- `BLOCKED_FAIL_CLOSED` input remains fail-closed through the DTO and validator;
- `REVIEW_ONLY_SOURCE_TRACE_DEGRADED` remains degraded review-only;
- `REVIEW_ONLY_SOURCE_TRACE` remains review-only;
- unsupported or incomplete input remains incomplete-safe.

P332 also verifies that `SourceTraceNumericSourceReadModelValidator` remains the safety gate for the assembled DTO.

## Safety Rules Verified

P332 verifies that:

- forbidden source types remain rejected by the validator;
- `ORDER_BOOK_DIRECT`, `ORDER_EXECUTION_PATH`, and `AUTO_TRADING_PATH` remain forbidden source types;
- safety flags remain required true through validation;
- `riskActionGuardRef` remains required by validation;
- missing fields remain `INCOMPLETE`;
- stale freshness remains `INCOMPLETE`;
- unknown freshness remains `INCOMPLETE`;
- missing downstream refs remain `INCOMPLETE`;
- `BigDecimal` values are preserved only when explicitly provided;
- source-only references can remain review-only without numeric values when refs are present;
- normal safe outputs do not contain executable semantics.
