# P260 Push Channel Disabled No-Op Java Skeleton

## 1. 阶段定位

P260 新增 future push channel delivery 的 disabled-by-default / no-op Java skeleton。

P260 只判断未来是否允许进入 delivery flow，不执行 push delivery，不连接任何 external provider，不发送任何消息。

P260 属于 B/C boundary Java disabled no-op skeleton，不是生产接线，不是 external Opportunity Push execution，不是 Readiness，不是 point generation，不是交易路径。

## 2. P259 已完成基线

P259 已通过 PR #637 合并到 main，当前 main 基准为：

```text
9299b2c BACKEND-P259 Opportunity Push Closure and External Channel Gate Pack (#637)
```

P259 已定义：

- future external channels may include Telegram / email / webhook / app notification / local notification
- P259 does not implement external channels
- future delivery must include throttling / idempotency / audit requirements
- P259 only documents those requirements
- Display Slots / 默认六币不能作为 batch universe
- Watchlist Pool 才是推送候选边界
- Risk Action Guard 必须位于 delivery 前
- 踩踏状态禁止机会推送
- 插针不等于趋势反转
- 强反转不等于直接反手
- Readiness / point generation / entry-stop-TP-RR 仍然 blocked

## 4. Java Skeleton 语义

P260 policy 可以引用 `OpportunityPushDTO` 作为输入，但不得执行 push delivery。

所有输出必须保持：

- review-only / fail-closed
- `manualReviewRequired=true`
- `notTradeInstruction=true`
- `externalPushSent=false`
- `deliveryAttempted=false`
- `deliveryEnabled=false`
- `readinessUpgraded=false`
- `tradingActionCreated=false`
- `entryStopTpRrGenerated=false`

safe review-only `OpportunityPushDTO` 最多只能生成 no-op review-only delivery decision。

missing / null / unsafe `OpportunityPushDTO` 必须 fail closed。

Risk Action Guard blockers / stampede / liquidity deterioration / wick-only reversal 必须阻断 delivery eligibility。

reasons / blockingReasons 必须保留，list 字段必须 defensive copy。

## 5. P260 不做

- 不接 Telegram。
- 不接 email。
- 不接 webhook。
- 不接 app notification。
- 不接 local notification。
- 不发送任何消息。
- 不接 external provider dependency。
- 不做 network call。
- 不接 scheduler。
- 不接 API / dashboard。
- 不读取 runtime / live / external data。
- 不创建 real scan loop。
- 不实现 external Opportunity Push execution。
- 不实现 Promote To Home runtime logic。
- 不升级 Readiness。
- 不生成 point generation。
- 不生成真实 entry / stop / TP / RR。
- 不接 order API / execution API / auto-trading。

## 6. 结论

P260 只新增 disabled no-op delivery policy skeleton。

Push delivery、external channel、Readiness、point generation 和交易路径仍未实现，后续必须另开授权门。
