# P277 Real Scan Contract Audit and Market-Read Boundary Plan

P277 is a docs-only Scope Pack after P276.

P277 audits the real scan contract and defines the market-read boundary plan. It is not an implementation package.

P277 does not write Java, tests, DTOs, dashboard code, schema, config, API, scheduler, MarketQuoteClient wiring, BinanceMarketQuoteClient wiring, runtime/live/external data reads, real scan loops, production ScanScore computation, Candidate production workflow, Opportunity Push execution, Readiness, point generation, entry/stop/TP/RR, order/execution, or auto-trading.

## Baseline

Current main before P277:

```text
dc0eb39 BACKEND-P276 Real Scan Score Candidate Return Scope Pack (#671)
```

P276 merged as `dc0eb39`.

P276 stopped the immediate external-channel no-op expansion and redirected the next planning direction back to real scan / real score / Candidate / Push preview. P277 is the first follow-up planning package on that path.

## Purpose

P277 defines a safe planning boundary for future real scan work:

- real scan contract audit
- market-read boundary plan
- Watchlist Pool scan universe boundary
- review-only / fail-closed / audit-only scan output contract
- runtime market-read still-blocked guard
- score / Candidate / Push still-blocked guard
- Readiness / point generation still-blocked guard

P277 does not implement DTOs, Java, adapters, services, schedulers, controllers, dashboards, scan loops, score computation, Candidate workflow, Push execution, external channel behavior, Readiness, point generation, or trading actions.

## Scan Universe

The future scan universe can only be Watchlist Pool.

Display Slots / 默认六币 cannot be used as a batch universe, default scan universe, or push universe. Display Slots are display priority only. 默认六币 are not a backend batch universe.

Any future real scan contract must prove watchlist membership before a symbol can enter scan output planning.

## Future Scan Output Contract

Future scan output must remain review-only / fail-closed / audit-only where applicable.

Future scan result contract may include:

- symbol
- source
- watchlist membership proof
- data availability
- stale/missing data state
- raw market-read references
- scan timestamp
- risk blockers
- downstream eligibility flags

P277 must not implement DTO / Java for that contract.

## Market-Read Boundary

P277 does not authorize runtime market reads.

The market-read plan may define future ownership and guardrails for market-read inputs, but it does not wire `MarketQuoteClient` or `BinanceMarketQuoteClient`, does not read runtime/live/external data, and does not create a real scan loop.

The recommended next package after P277 should be one of:
