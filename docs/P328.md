# P328 SourceTraceNumericSourceContextDTO Java Skeleton

## Purpose

P328 belongs to the Readiness / Point Mainline.

P328 follows P327 `SOURCETRACE_NUMERIC_SOURCE_READ_MODEL_PLAN`.

P328 adds a minimal plain Java DTO skeleton for `SourceTraceNumericSourceContextDTO` and targeted DTO tests.

The DTO is only a carrier for future SourceTrace numeric source read model fields.

P328 is not a validator, not an assembler, not service wiring, not dashboard runtime integration, not external push, and not order / execution / auto-trading.

## Status And Factory Boundary

The DTO supports:

- `INCOMPLETE`;
- `BLOCKED_FAIL_CLOSED`;
- `REVIEW_ONLY_SOURCE_TRACE`;
- `REVIEW_ONLY_SOURCE_TRACE_DEGRADED`.

Factories are limited to:

- `incomplete(...)`;
- `blockedFailClosed(...)`;
- `reviewOnly(...)`;
- `degraded(...)`.

All factories force:

- `reviewOnly = true`;
- `notTradeInstruction = true`;
- `manualReviewRequired = true`;
- `incompleteSafe = true`.

`blockedFailClosed(...)` forces `failClosed = true` and requires a blocked reason.

`incomplete(...)` requires a missing reason.

`degraded(...)` requires a missing reason.

`reviewOnly(...)` only carries explicitly provided values and does not compute numeric fields.

No factory, setter, or builder can turn safety flags off.

## Numeric Field Role Boundary

`numericFieldRole` can carry:

- `ENTRY_PRICE`;
- `ENTRY_ZONE_LOW`;
- `ENTRY_ZONE_HIGH`;
- `STOP_PRICE`;
- `STOP_ZONE_LOW`;
- `STOP_ZONE_HIGH`;
- `TAKE_PROFIT_PRICE`;
- `TAKE_PROFIT_ZONE_LOW`;
- `TAKE_PROFIT_ZONE_HIGH`;
- `RISK_REWARD_VALUE`;
- `SOURCE_ONLY_REFERENCE`.

These are field roles only.

`ENTRY_PRICE` is not a buy / long / open instruction.

`STOP_PRICE` is not a stop-loss order, market close, or one-shot market cut.

`TAKE_PROFIT_PRICE` is not a take-profit order or sendable order.

`RISK_REWARD_VALUE` is not an opening condition and cannot override Risk Action Guard.

## Test Coverage

The targeted test verifies:

- incomplete safety flags stay true;
- blocked fail-closed status forces `failClosed = true`;
- blocked / incomplete / degraded factories require reasons;
- review-only factory carries explicit BigDecimal fields without calculating them;
- numeric fields can remain null and incomplete-safe;
- allowed and forbidden source type enums exist;
- numeric field roles cover entry / stop / TP / RR;
- freshness and source trace status enums exist;

- the DTO has no Spring annotations;
- the DTO has no service, controller, mapper, repository, scheduler, provider, market client, HTTP client, data source, external push, order, execution, or auto-trading class dependency;
- public status / reason outputs do not contain executable trade semantics.
