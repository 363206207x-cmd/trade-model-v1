P353 is an A-risk docs-only runtime DTO plan in the Readiness / Point Mainline.

P353 adds no Java, no tests, no runtime wiring, no service, no dashboard, no external channel, no Push send, no order, no execution, and no auto-trading.

- `INCOMPLETE`;
- `BLOCKED_FAIL_CLOSED`;
- `REVIEW_ONLY_RUNTIME_CANDIDATE`;
- `REVIEW_ONLY_RUNTIME_CANDIDATE_DEGRADED`.

## Safety Flags

The future DTO must force:

- `reviewOnly=true`;
- `notTradeInstruction=true`;
- `manualReviewRequired=true`;
- `incompleteSafe=true`;
- `failClosed=true` only when status is `BLOCKED_FAIL_CLOSED`.

No constructor, factory, setter, or builder may allow callers to disable the safety flags.

## Factory Rules

Future DTO factories should include:

- `incomplete(...)`;
- `blockedFailClosed(...)`;
- `degraded(...)`;
- `reviewOnly(...)`.

Factory rules:

- `incomplete(...)` must require missingReason or candidateUnavailableReason.
- `blockedFailClosed(...)` must require blockedReason or candidateBlockedReason.
- `degraded(...)` must require degradedReason or candidateDegradedReason.
- `reviewOnly(...)` must preserve all review-only safety flags.
- list fields must be defensively copied.
- factories must not output executable point, direction, or action fields.

## Watchlist Pool Boundary

Watchlist Pool is the maximum boundary for candidate / opportunity push eligibility.

Display Slots and default home assets are not Watchlist Pool Proof.

Default display does not mean push is allowed.

Assets outside the Watchlist Pool must not enter candidates.

P353 does not connect Watchlist service, read rule config, or read audit table.

## Risk Action Guard Boundary

High risk does not mean immediate stop, immediate reverse, or immediate open.

Strong reversal does not mean direct reverse.

Wick-only evidence does not mean trend reversal.

Stampede state forbids opportunity push, reverse, and new open semantics.

Liquidity degradation must not become one-shot market cut semantics.

P353 does not generate executable risk actions.

## Disabled-By-Default Inheritance

Any future runtime using this DTO must remain disabled-by-default.

By default it must not:

- participate in production decisions;
- affect dashboard output;
- send Push;
- generate point proposals;
- change existing decision results.

When config is off, future runtime must fail-closed or no-op.

When config is on, it may only output review-only runtime candidate status.
