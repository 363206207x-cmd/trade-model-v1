# P327 SourceTrace Numeric Source Read Model Plan

## Purpose

P327 belongs to the Readiness / Point Mainline.

P327 follows P326 `SOURCE_CONTEXT_INTEGRATION_PLAN`.

P327 is a docs-only plan for a future `SourceTraceNumericSourceContext` read model.

It defines how future entry / stop / TP / RR numeric source traces must be represented before they can enter the review-only numeric point candidate chain.

P327 is not Java, not tests, not service wiring, not dashboard runtime integration, not external push, and not order / execution / auto-trading.

## Responsibility Boundary

`SourceTraceNumericSourceContext` is the source identity for numeric fields.

It may describe where a numeric field came from, what field role it serves, which upstream contexts it references, and why it is missing or blocked.

It must not:

- calculate entry;
- calculate stop;
- calculate TP;
- calculate RR;
- infer numeric fields from latest price alone;
- infer numeric fields from latest close alone;
- infer numeric fields from score labels, candidate labels, AI prose, dashboard text, final-decision text, or Display Slots;
- bypass RuntimeKlineContext;
- bypass DataQualityContext;
- bypass MultiTimeframeContext;
- bypass RiskActionGuardContext;
- bypass `NumericPointSafetyValidator`;
- connect service runtime, dashboard runtime, external channel, Push send, order, execution, or auto-trading.

## Chain Position

The future chain position is:

`Market/Evidence Input -> SourceTrace Numeric Source Read Model -> RuntimeKlineContext -> DataQualityContext -> MultiTimeframeContext -> RiskActionGuardContext -> SourceOwnedNumericPointCandidateAssembler -> ReviewOnlyNumericPointProposalAssembler -> NumericPointSafetyValidator`

SourceTrace is the numeric field's source identity, not a point calculator.

SourceTrace can only feed later gates when the later gates are present and still pass.

SourceTrace alone never makes a point candidate executable.

## Relationship To Existing Skeletons

`SourceOwnedNumericPointCandidateAssembler` can only move source-owned input context into explicit proposal assembly input.

Future SourceTrace read model output may become one upstream source for those source-owned contexts.

The source-owned assembler must still call `ReviewOnlyNumericPointProposalAssembler`.

The explicit assembler must still call `NumericPointSafetyValidator`.

RuntimeKlineContext, DataQualityContext, MultiTimeframeContext, and RiskActionGuardContext remain mandatory downstream gates.

P327 does not implement any of these links.

## Allowed Future Source Types

Allowed source types are source-owned evidence categories only:

- `STRUCTURE_LEVEL`;
- `INVALIDATION_LEVEL`;
- `LIQUIDITY_POOL_LEVEL`;
- `PRIOR_HIGH_LOW_LEVEL`;
- `VWAP_OR_VOLUME_LEVEL`;
- `ATR_REFERENCE_LEVEL`;
- `MULTITIMEFRAME_CONFIRMATION_LEVEL`;
- `RISK_ACTION_GUARD_REFERENCE`;
- `MANUAL_REVIEW_SOURCE`.

These source types only identify source evidence.

They do not authorize automatic point generation.

They do not authorize executable entry / stop / TP / RR.

They do not authorize external push, order, execution, or auto-trading.

## Forbidden Source Types

Forbidden source types include:

- `AI_PROSE_ONLY`;
- `DASHBOARD_TEXT_ONLY`;
- `SCORE_LABEL_ONLY`;
- `FINAL_DECISION_TEXT_ONLY`;
- `LATEST_PRICE_ONLY`;
- `LATEST_CLOSE_ONLY`;
- `HARDCODED_DEFAULT`;
- `MANUALLY_INVENTED_FALLBACK`;
- `DISPLAY_SLOT_ONLY`;
- `ORDER_BOOK_DIRECT`;
- `EXTERNAL_PROVIDER_DIRECT`;
- `ORDER_EXECUTION_PATH`;
- `AUTO_TRADING_PATH`.

If the source is only insufficient, the result must be `INCOMPLETE`.

If the source is forged, untrusted, executable, or attempts to bypass gates, the result must be `BLOCKED_FAIL_CLOSED`.

## Numeric Field Roles

Future `numericFieldRole` must support:

- `ENTRY_PRICE`;
- `ENTRY_ZONE_LOW`;
- `ENTRY_ZONE_HIGH`;
- `STOP_PRICE`;
- `STOP_ZONE_LOW`;
- `STOP_ZONE_HIGH`;
- `TAKE_PROFIT_PRICE`;
- `TAKE_PROFIT_ZONE_LOW`;
- `TAKE_PROFIT_ZONE_HIGH`;
- `RISK_REWARD_VALUE`;
- `SOURCE_ONLY_REFERENCE`.

`numericFieldRole` is only a field role.

`ENTRY_PRICE` is not buy, long, open, or order intent.

`STOP_PRICE` is not stop-loss order, market close, or one-shot market cut.

`TAKE_PROFIT_PRICE` is not take-profit order or sendable order.

`RISK_REWARD_VALUE` is not an opening condition and cannot override RiskActionGuard.

## INCOMPLETE Conditions

The future read model must output `INCOMPLETE` when:

- `sourceTraceId` is missing;
- `sourceOwner` is missing;
- `sourceType` is missing;
- `sourceContractId` is missing;
- `symbol` is missing;
- `market` is missing;
- `timeframe` is missing;
- `numericFieldName` is missing;
- `numericFieldRole` is missing;
- numeric value is missing and no `missingReason` exists;
- `sourceRef` is missing;
- `observedAt` is missing;
- `freshnessStatus` is stale or unknown;
- `runtimeKlineContextRef` is missing;
- `dataQualityContextRef` is missing;
- `multiTimeframeContextRef` is missing;
- `riskActionGuardRef` is missing;
- symbol / market / timeframe mismatch exists;
- allowed source type has insufficient numeric proof;
- input is latest-price-only;
- input is score-label-only;
- input is AI-prose-only;
- input is dashboard-text-only;
- input is Display Slots only;
- `missingReason` is absent when source cannot be produced.

## BLOCKED_FAIL_CLOSED Conditions

The future read model must output `BLOCKED_FAIL_CLOSED` when:

- `trustedSource = false`;
- source is forged;
- source is untrusted;
- source contract mismatch is paired with executable output;
- `reviewOnly = false`;
- `notTradeInstruction = false`;
- `manualReviewRequired = false`;
- source contains buy / sell / long / short / open / close / reverse / order / execute semantics;
- source attempts to bypass RuntimeKlineContext;
- source attempts to bypass DataQualityContext;
- source attempts to bypass MultiTimeframeContext;
- source attempts to bypass RiskActionGuardContext;
- source attempts to bypass `NumericPointSafetyValidator`;
- source comes from order / execution / auto-trading path;
- external provider direct read is used as SourceTrace without upstream contract;
- hardcoded default numeric value is used;
- manually invented fallback numeric value is used.

## Preventing Fabricated Points

SourceTrace must never be allowed to become point fabrication.

The read model must require source identity, field role, timestamp, freshness, source ref, and downstream context refs.

If any source is only a label, prose, display text, latest price, latest close, hardcoded fallback, or manually invented value, it cannot support a numeric candidate.

If the source tries to produce executable semantics, the model must fail closed.
