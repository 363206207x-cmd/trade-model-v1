## DTO Factory Rules Implemented

P349 implements explicit factory selection:

- null input -> DTO `incomplete(...)`;
- `requestedStatus = INCOMPLETE` -> DTO `incomplete(...)`;
- `requestedStatus = BLOCKED_FAIL_CLOSED` -> DTO `blockedFailClosed(...)`;
- `requestedStatus = REVIEW_ONLY_SOURCE_OWNED_CANDIDATE_INTEGRATION_BINDING_DEGRADED` -> DTO `degraded(...)`;
- `requestedStatus = REVIEW_ONLY_SOURCE_OWNED_CANDIDATE_INTEGRATION_BINDING` -> DTO `reviewOnly(...)`;
- null or unsupported status -> DTO `incomplete(...)`.

The assembler does not calculate status.

The assembler does not infer direction.

The assembler does not promote degraded or incomplete input into review-only success.

The assembler does not modify DTO after validation failure.

The assembler does not drop validation reasons.
