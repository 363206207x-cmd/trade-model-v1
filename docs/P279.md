# P279 Real Scan Input Contract DTO Skeleton

P279 adds a DTO-only / enum-only / targeted-test-only skeleton for the future real scan input contract.

P278 merged as `04f32c8` (`BACKEND-P278 Real Scan Input Contract DTO Authorization Gate (#675)`). P279 follows that authorization gate and does not implement services, Spring wiring, controllers, endpoints, APIs, schedulers, market reads, scan loops, score computation, Candidate production workflow, Opportunity Push execution, Readiness, point generation, entry-stop-TP-RR, order/execution, or auto-trading.

## Scope

P279 adds:

- `RealScanInputContractDTO`
- `RealScanInputContractStatusEnum`
- `RealScanInputContractDTOTest`
- `PHASE_P279_REAL_SCAN_INPUT_CONTRACT_DTO_SKELETON_VERIFICATION.md`

The DTO is review-only and fail-closed by default. It defaults `manualReviewRequired=true` and `notTradeInstruction=true`.

## Contract Shape

The DTO contains only input-contract fields:

- symbol
- source
- requestedScanReason
- watchlistPoolMember
- watchlistPoolProof
- watchlistConfigVersion
- requestedTimeframes
- scanTimestamp
- marketReadRequired
- dataAvailabilityExpected
- staleInputBehavior
- missingInputBehavior
- riskBlockers
- reviewOnlySafetyFlags
- status
- blockingReasons
- manualReviewRequired
- notTradeInstruction

Missing Watchlist Pool proof fails closed. Non-watchlist input fails closed. List fields are defensively copied.

## Explicit Non-Scope

P279 does not add:

- services or Spring annotations
- controller / endpoint / API
- scheduler
- `MarketQuoteClient` / `BinanceMarketQuoteClient`
- runtime/live/external data reads
- real scan loop
- production ScanScore computation
- Candidate production workflow
- Opportunity Push execution
- external channel behavior
- provider credentials / live provider calls / message rendering / sending
- Readiness / point generation / entry-stop-TP-RR / order / execution / auto-trading

The DTO does not contain trade action, order, execution, entry, stop, take profit, RR, provider, external channel, message sending, or readiness fields.

Display Slots / 默认六币 cannot be scan universe or batch universe. Watchlist Pool remains the scan candidate boundary. Risk Action Guard must remain before delivery / Push / Readiness.
