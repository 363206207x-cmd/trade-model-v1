# P299 Score-to-Candidate Handoff Review-Only Slice

P299 is the Candidate / Push Mainline entry（候选 / 推送主线入口）.

P299 continues from P298 review-only score assembly.

P299 adds a review-only score-to-candidate handoff skeleton so `ReviewOnlyScoreAssemblyDTO` can become a safe `ReviewOnlyCandidateHandoffDTO` for later Candidate Attention review-only work.

P299 is not a real Candidate.

P299 does not generate Candidate Attention.

P299 does not generate Promote To Home.

P299 does not generate Opportunity Push.

P299 does not generate Readiness.

P299 does not generate point generation, entry, stop, TP, RR, final direction, long-short signal, order intent, execution intent, or auto-trading.

P299 does not connect `MarketQuoteClient` or `BinanceMarketQuoteClient`.

The user value is that review-only score assembly no longer stops at the score assembly object. It can now move into a candidate handoff skeleton for later review-only candidate attention / candidate preview while remaining manual-review required and non-executable.
