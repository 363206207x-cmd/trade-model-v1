# P293 MarketReadRequest Review-Only Output Assembler

P293 belongs to the Market Read Mainline（行情读取主线）.

It continues from P292 MarketReadRequest Test-Only Wiring（P292 行情读取请求仅测试接线）. P292 proved that `MarketReadRequestDTO` can flow into `MarketReadRequestGuardValidator` inside test scope and return a safe guard validation result.

## Scope

P293 adds a review-only output assembler for MarketReadRequest.

The new slice turns:

- `MarketReadRequestDTO`
- `MarketReadRequestGuardValidationResult`

into a readable review-only output DTO for manual review.

## User Value

Before P293, the project could validate a market-read request but the result still looked like a validator result.

After P293, the request validation state becomes a readable review-only output with:

- symbol
- request id
- source contract id
- watchlist pool proof
- requested timeframes
- guard validation status
- validation / blocking reasons
- risk blockers
- review-only safety flags
- allowed next step
- review-only message

This makes the next Market Read chain step easier to inspect without implying production runtime behavior.

## Boundaries

P293 is not production market read.

P293 does not connect:

- `MarketQuoteClient`
- `BinanceMarketQuoteClient`
- provider client
- runtime/live/external data read
- controller / endpoint / API
- mapper / repository / DB write
- scheduler

P293 does not generate:

- scan output
- ScanScore
- Candidate / Candidate Attention / Promote To Home
- Opportunity Push
- Readiness
- point generation
- entry / stop / TP / RR
- order / execution / auto-trading

## Capability Movement

P293 moves the MarketReadRequest path from `TEST_ONLY_WIRING` toward `REVIEW_ONLY_OUTPUT_SKELETON`.

It is still non-executable, manual-review required, and not a trade instruction.
