# P317 Risk Action Guard Numeric Point Contract Plan

## Purpose

P317 belongs to the Readiness / Point Mainline.

P317 is a docs-only Risk Action Guard contract plan after P316 `MULTITIMEFRAME_NUMERIC_POINT_CONTRACT_PLAN`.

It defines how every future entry / stop / TP / RR numeric point must pass Risk Action Guard before it can enter review-only numeric point proposal consideration.

P317 does not create Java DTOs, does not implement numeric point proposal, does not generate real entry / stop / TP / RR, does not connect dashboard runtime, does not connect external channels, and does not connect order / execution / auto-trading.

## What P317 Is Not

P317 is docs-only.

P317 does not raise Production Runtime Progress.

P317 does not mean Risk Action Guard Java DTO is complete.

P317 does not mean numeric point proposal is implemented.

P317 does not mean real entry / stop / TP / RR are complete.

P317 does not mean dashboard runtime integration.

P317 does not mean external push.

P317 does not mean order, execution, or auto-trading.

P317 does not allow direct order placement after merge.

## Risk Action Guard Contract Boundary

Risk Action Guard is the hard review-only safety gate between confirmed numeric-point context and any future review-only numeric point proposal.

It must answer:

- whether high risk can still produce a review-only risk note;
- whether liquidity degradation blocks executable-like behavior;
- whether stampede, wick-only, strong reversal, or high-timeframe conflict must become `INCOMPLETE` or `BLOCKED_FAIL_CLOSED`;
- whether entry / stop / TP / RR may be considered only as review-only, manual-review-required, non-trade-instruction context.

Risk Action Guard cannot generate entry / stop / TP / RR.

Risk Action Guard cannot replace SourceTrace, RuntimeKlineContext, DataQuality, or MultiTimeframe contracts.

Risk Action Guard cannot authorize external push, order intent, execution intent, or auto-trading.

## Chain Position

Risk Action Guard must sit here:

`SourceTrace -> RuntimeKlineContext -> DataQuality -> MultiTimeframe -> Risk Action Guard -> Review-only Numeric Point Proposal`

Risk Action Guard must execute before review-only numeric point proposal consideration.

It cannot be bypassed by SourceTrace, RuntimeKlineContext, DataQuality, MultiTimeframe, AI prose, Dashboard display, Push, external channel, order API, execution API, or auto-trading paths.

## Minimum Risk Action Guard Fields

Every future numeric point Risk Action Guard context must include at least:

| Field | Required meaning |
|---|---|
| `riskActionGuardContextId` | Stable guard context id. Missing id means `INCOMPLETE`. |
| `symbol` | Symbol that matches upstream SourceTrace, RuntimeKlineContext, DataQuality, and MultiTimeframe contexts. |
| `market` | Market or venue context. |
| `requestedTimeframes` | Timeframes requested for review. |
| `sourceTraceRefs` | SourceTrace refs that support the proposed point context. |
| `runtimeKlineContextRefs` | RuntimeKlineContext refs used by the proposed point context. |
| `dataQualityContextRef` | DataQuality context ref. |
| `multiTimeframeContextRef` | MultiTimeframe context ref. |
| `overallRiskLevel` | Overall risk level entering the guard. |
| `liquidityState` | Liquidity state used by the guard. |
| `liquiditySeverity` | Severity of liquidity degradation. |
| `stampedeState` | Stampede state. |
| `wickStatus` | Wick / pin-bar state. |
| `wickConfirmationStatus` | Confirmation status for wick / pin-bar behavior. |
| `strongReversalStatus` | Strong reversal state. |
| `strongReversalConfirmationStatus` | Multi-source confirmation status for strong reversal. |
| `highTimeframeConflictStatus` | High-timeframe conflict state. |
| `proposedPointStatus` | Review-only proposed point status, never executable. |
| `allowedReviewOnlyActions` | Allowed review-only actions, such as risk note or point review consideration. |
| `forbiddenActions` | Forbidden actions, including reverse, open, order, execution, external opportunity push, and auto-trading. |
| `requiredRecheckReasons` | Reasons a recheck is required. |
| `manualReviewRequired` | Must be true. |
| `notTradeInstruction` | Must be true. |
| `reviewOnly` | Must be true. |
| `missingReason` | Required when context is unavailable or incomplete. |
| `blockedReason` | Required when fail-closed. |

## Core Guard Rules

Risk Action Guard must enforce these rules:

- high risk does not mean immediate stop;
- high risk does not mean immediate reverse;
- high risk does not mean immediate open;
- strong reversal does not mean direct reverse;
- wick or pin-bar does not mean trend reversal;
- stampede state blocks opportunity push;
- degraded liquidity must not become one-shot market cut;
- short-term wick can only trigger risk reminder and wait-for-confirmation state;
- point generation must happen after Risk Action Guard;
- even a future review-only numeric point must keep `reviewOnly = true`, `notTradeInstruction = true`, and `manualReviewRequired = true`.

## Risk High Plus Liquidity Normal

Allowed review-only outputs:

- review-only risk reduction note;
- review-only stop review;
- review-only position-size review;
- recheck required;
- manual review required.

Forbidden outputs:

- market close instruction;
- immediate reverse;
- new open;
- external push as opportunity;
- order / execution / auto-trading.

## Risk High Plus Liquidity Degraded

Allowed review-only outputs:

- review-only risk warning;
- review-only staged risk reduction note;
- wait-for-liquidity-recovery note;
- recheck required;
- manual review required.

Forbidden outputs:

- one-shot market cut;
- immediate reverse;
- new open;
- opportunity push;
- executable stop / TP / entry;
- order / execution / auto-trading.

## Risk High Plus Stampede Confirmed

The guard must return `BLOCKED_FAIL_CLOSED`.

Required blocking outcomes:

- opportunity push blocked;
- reverse blocked;
- new open blocked;
- external channel blocked unless a later separately authorized emergency non-trade alert scope exists;
- order / execution / auto-trading blocked.

## Risk High Plus Wick Only Or Pin-Bar Only

The guard must return `INCOMPLETE` unless MultiTimeframe and DataQuality confirm the signal.

Required outcomes:

- no trend reversal conclusion;
- no reverse;
- no new entry;
- no executable point;
- recheck required.

## Strong Reversal

Strong reversal can enter review-only consideration only when SourceTrace, RuntimeKlineContext, DataQuality, MultiTimeframe, and Risk Action Guard all pass.

Strong reversal must not directly generate:

- reverse;
- short;
- long;
- close position;
- order intent;
- execution intent;
- auto-trading.

## Entry Risk Action Guard Contract

Entry numeric point review requires:

- Risk Action Guard executed;
- `liquidityState` not severely degraded;
- `stampedeState` not confirmed;
- wick-only not treated as trend reversal;
- strong reversal confirmed across required contexts;
- high-timeframe conflict not trade-inducing;
- `allowedReviewOnlyActions` includes entry review consideration;
- `forbiddenActions` does not block entry review;
- `reviewOnly`, `notTradeInstruction`, and `manualReviewRequired` are all true.

Entry Risk Action Guard passing is not buy, long, open, or order instruction.

## Stop Risk Action Guard Contract

Stop numeric point review requires:

- Risk Action Guard executed;
- high risk not automatically converted to immediate stop;
- degraded liquidity not converted to one-shot market cut;
- stampede confirmed blocks review;
- wick-only not converted to trend-reversal stop;
- `allowedReviewOnlyActions` allows only stop review consideration;
- `reviewOnly`, `notTradeInstruction`, and `manualReviewRequired` are all true.

Stop Risk Action Guard passing is not an automatic stop-loss order and not a market close suggestion.

## TP Risk Action Guard Contract

TP numeric point review requires:

- Risk Action Guard executed;
- liquidity and stampede state safe enough for review-only consideration;
- TP not sendable as an order;
- TP not allowed to bypass manual review;
- `allowedReviewOnlyActions` allows only TP review consideration;
- `reviewOnly`, `notTradeInstruction`, and `manualReviewRequired` are all true.

TP Risk Action Guard passing is not an automatic take-profit order and not a sendable order.

## RR Risk Action Guard Contract

RR numeric review field requires:

- entry / stop / TP Risk Action Guard refs are consistent;
- RR does not authorize open by itself;
- RR does not override high-risk state by itself;
- RR does not turn high risk into opportunity;
- `reviewOnly`, `notTradeInstruction`, and `manualReviewRequired` are all true.

RR cannot be used alone as an open-position condition.

## INCOMPLETE Conditions

The guard must return `INCOMPLETE` for at least:

- `riskActionGuardContextId` missing;
- `sourceTraceRefs` missing;
- `runtimeKlineContextRefs` missing;
- `dataQualityContextRef` missing;
- `multiTimeframeContextRef` missing;
- `overallRiskLevel` unknown;
- `liquidityState` unknown;
- `stampedeState` unknown;
- `wickStatus` unknown;
- `wickConfirmationStatus` unknown;
- `strongReversalStatus` unknown;
- `strongReversalConfirmationStatus` missing;
- `highTimeframeConflictStatus` unknown;
- `allowedReviewOnlyActions` missing;
- `forbiddenActions` missing;
- `requiredRecheckReasons` missing when recheck is required;
- `manualReviewRequired` not true;
- `notTradeInstruction` not true;
- `reviewOnly` not true;
- `missingReason` absent when context is unavailable.

## BLOCKED_FAIL_CLOSED Conditions

The guard must return `BLOCKED_FAIL_CLOSED` for at least:

- Risk Action Guard bypass attempted;
- context forged or untrusted;
- stampede confirmed;
- severely degraded liquidity with executable output attempted;
- wick-only treated as trend reversal;
- strong reversal treated as direct reverse;
- high-timeframe conflict would induce immediate reverse;
- proposed point implies buy / sell / long / short;
- proposed point implies order intent;
- proposed point implies execution intent;
- proposed point implies auto-trading;
- proposed point implies external opportunity push during blocked state;
- manual review bypass attempted;
- `reviewOnly`, `notTradeInstruction`, or `manualReviewRequired` set false.
