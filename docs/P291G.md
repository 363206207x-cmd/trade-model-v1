# P291G Workflow Auto-Decision Runner Pack

P291G is a workflow auto-decision runner package.

It does not advance business functionality.

Its purpose is to replace menu-first workflows with a non-interactive status and next-step decision command:

```bash
bash scripts/v1-auto.sh
```

For approved current-PR merges, use:

```bash
bash scripts/v1-merge-current.sh
```

`v1-auto.sh` detects the current PR from the current branch first, then from `docs/ACTIVE_MAINLINE_STATUS.yml`. It does not treat old open PRs, open Issues, or branches as the current task.

`v1-merge-current.sh` is only for use after the user has explicitly approved the merge. B/C or C risk PRs still require explicit user approval before merge.

This package does not change the Source of Truth and does not change the current business mainline.

This package does not advance Market Read, scan output, score, Candidate, Push, Readiness, point generation, entry / stop / TP / RR, order execution, execution API, or auto-trading.
