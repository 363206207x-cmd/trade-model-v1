# P291D Workflow Command Automation Pack

P291D is a workflow automation package.

It does not advance business functionality, market read runtime behavior, scan output, score, Candidate, Push, Readiness, point generation, or trading paths.

## Purpose

P291D reduces repeated copy-paste in the V1 workflow and helps prevent new-window drift.

The package keeps P291C workflow enforcement in place while adding reusable commands for:

- status checks;
- PR review input;
- merge and sync after explicit approval;
- safe checks after Codex work;
- session bootstrap;
- next-pack context.

## Daily Commands

Use these commands going forward:

```bash
bash scripts/v1-status.sh
bash scripts/v1-pr-review-input.sh <PR_NUMBER>
bash scripts/v1-merge-sync.sh <PR_NUMBER> "<SUBJECT>"
bash scripts/v1-safe-check.sh
bash scripts/v1-session-bootstrap.sh
bash scripts/v1-next-pack-context.sh
```

## Boundary

This package is scripts/docs only.

It does not modify Java, tests, DTOs, dashboard, schema, config, resources, services, controllers, mappers, repositories, schedulers, APIs, market clients, or trading logic.

`v1-merge-sync.sh` must be run only after the user explicitly agrees to merge the target PR.
