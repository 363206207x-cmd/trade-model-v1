# P291E Workflow One-Command Runner Pack

P291E is a workflow one-command runner package.

It does not advance business functionality.

Its purpose is to reduce repeated copy-paste by adding one terminal entry point:

```bash
bash scripts/v1.sh
```

The menu delegates to the existing P291D workflow commands for status, session bootstrap, PR review input, merge-sync after explicit approval, safe-check, and next-pack context.

B/C or C risk PR merges still require explicit user approval before the merge option may be used. The merge menu reminds the operator that it should only run after the user explicitly said: `同意合并 PR #xxx`.

This package does not change the Source of Truth and does not change the current business mainline.

This package does not advance Market Read, Score, Candidate, Push, Execution Advice, point generation, order execution, or auto-trading.
