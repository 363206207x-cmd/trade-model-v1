# P300 Candidate Attention Review-Only Slice

P300 belongs to the Candidate / Push Mainline.

P300 continues from P299's review-only candidate handoff and adds a review-only candidate attention skeleton.

This package turns `ReviewOnlyCandidateHandoffDTO` into `ReviewOnlyCandidateAttentionDTO` through a small assembler. The output is still a manual-review object: it is review-only, not a trade instruction, and requires manual review.

P300 is not a real Candidate implementation.

P300 does not generate candidate rank or candidate score.

P300 does not generate Promote To Home.

P300 does not generate Opportunity Push.

P300 does not generate Readiness.

P300 does not generate point generation, entry, stop, TP, or RR.

P300 does not connect `MarketQuoteClient` or `BinanceMarketQuoteClient`.

P300 does not read runtime, live, or external market data.

The user value is that a review-only candidate handoff can now move into a safe candidate attention object for later candidate preview / ranking guard work instead of stopping at the handoff object.
