# P295 Review-Only Scan Output to Evidence / Score Entry Slice

P295 belongs to the Evidence / Score Mainline（证据 / 评分主线）.

P295 continues from P294 review-only scan output.

P295 adds a review-only Evidence / Score entry envelope and assembler so `MarketReadReviewOnlyScanOutputDTO` can enter the later evidence / score chain as safe manual-review input.

P295 is not real evidence generation.

P295 does not calculate the eight score dimensions.

P295 does not generate Candidate, Push, Readiness, point generation, entry, stop, TP, RR, order intent, execution intent, or auto-trading.

P295 does not connect `MarketQuoteClient` or `BinanceMarketQuoteClient`.

The user value is that review-only scan output can become a structured entry point for later evidence / score work instead of stopping at scan output.
