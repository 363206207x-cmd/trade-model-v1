# P356 Source-Owned Candidate Integration Runtime Validator Java Skeleton

## Package Type

P356 is a B-risk Java/test Runtime Validator skeleton package in the Readiness / Point Mainline.

It follows P355 and adds only a plain Java validator skeleton plus targeted validator tests for the P354 `SourceOwnedCandidateIntegrationRuntimeCandidateDTO`.

P356 adds no Runtime Assembler, no Runtime Orchestrator, no service, no controller, no mapper, no repository, no scheduler, no dashboard runtime, no external channel, no Push send, no order, no execution, and no auto-trading.

## Capability Movement

`SOURCE_OWNED_CANDIDATE_INTEGRATION_RUNTIME_VALIDATOR_PLAN -> SOURCE_OWNED_CANDIDATE_INTEGRATION_RUNTIME_VALIDATOR_JAVA_SKELETON`

This movement completes L2 Runtime Validator only.

It does not complete runtime assembly, runtime orchestration, internal wiring, dashboard preview, runtime-safe usage, point generation, final direction, push sending, or trading.

## Completed Scope

P356 adds:

- `SourceOwnedCandidateIntegrationRuntimeCandidateValidator`;
- `SourceOwnedCandidateIntegrationRuntimeCandidateValidatorTest`;
- `ValidationStatus` values for incomplete, blocked fail-closed, degraded, and review-only valid runtime candidate status;
- `ValidationResult` with forced review-only safety flags and immutable reasons;
- safety flag checks for `reviewOnly`, `notTradeInstruction`, `manualReviewRequired`, and `incompleteSafe`;
- fail-closed checks for disabled safety flags, blocked upstream status, untrusted source flags, RiskActionGuard blocks, WatchlistPoolProof blocks, and forbidden executable semantics;
- incomplete checks for missing runtime status, required refs, observedAt, completeness score, stale runtime kline, insufficient data quality, unconfirmed multi-timeframe context, stale WatchlistPoolProof, and incomplete upstream sources;
- degraded checks that require degraded reasons and never upgrade degraded input to full review-only valid;
- targeted tests for incomplete, blocked, degraded, review-only valid, forbidden semantics, safety flags, immutable reasons, and forbidden dependency boundaries.

## Runtime Validator Position

`SourceOwnedCandidateIntegrationRuntimeCandidateValidator` is only a plain Java safety gate for `SourceOwnedCandidateIntegrationRuntimeCandidateDTO`.

It validates whether a DTO is safe as a review-only runtime candidate status carrier.

It is not:

- runtime candidate generation;
- a point proposal;
- final direction;
- push payload;
- trade instruction;
- order intent;
- execution intent;
- auto-trading action;
- service runtime output.

## Validation Status

The validator status enum is:

- `INCOMPLETE`;
- `BLOCKED_FAIL_CLOSED`;
- `REVIEW_ONLY_RUNTIME_CANDIDATE_VALID`;
- `REVIEW_ONLY_RUNTIME_CANDIDATE_DEGRADED`.

`REVIEW_ONLY_RUNTIME_CANDIDATE_VALID` is not a buy signal.

`REVIEW_ONLY_RUNTIME_CANDIDATE_VALID` is not a sell signal.

`REVIEW_ONLY_RUNTIME_CANDIDATE_VALID` is not a final direction.

`REVIEW_ONLY_RUNTIME_CANDIDATE_VALID` is not a point.

`REVIEW_ONLY_RUNTIME_CANDIDATE_VALID` is not push sending.

`REVIEW_ONLY_RUNTIME_CANDIDATE_VALID` is not a trade action.

## Safety Boundary

The validator result forces:

- `reviewOnly=true`;
- `notTradeInstruction=true`;
- `manualReviewRequired=true`;
- `incompleteSafe=true`;
- `failClosed=true` only when status is `BLOCKED_FAIL_CLOSED`.

The validator must not express order, execution, or auto-trading intent.

The validator reasons are defensively copied and immutable.
