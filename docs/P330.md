# P330 SourceTrace Numeric Source Validator Verification

## Purpose

P330 belongs to the Readiness / Point Mainline.

P330 follows P329 `SOURCETRACE_NUMERIC_SOURCE_READ_MODEL_VALIDATOR_JAVA_SKELETON`.

P330 is a docs-only verification package for the P327-P329 SourceTrace numeric source read model chain.

It verifies what the chain can do, what it still cannot do, and why it must not move directly into RuntimeKlineContext wiring, service runtime, dashboard runtime, true point generation, external push, order, execution, or auto-trading.

P330 is not Java, not tests, not a DTO, not a validator, not an assembler, not service wiring, not dashboard runtime integration, not external push, and not order / execution / auto-trading.

## P327 Verification

P327 is the SourceTrace numeric source read model docs-only plan.

It defines the SourceTrace numeric source read model responsibility boundary:

- SourceTrace is the source identity for numeric fields;
- SourceTrace may describe source ownership, field role, upstream refs, freshness, missing reason, and blocked reason;
- SourceTrace is not a point calculator;
- SourceTrace does not calculate entry;
- SourceTrace does not calculate stop;
- SourceTrace does not calculate TP;
- SourceTrace does not calculate RR.

P327 also defines that SourceTrace cannot bypass:

- RuntimeKlineContext;
- DataQualityContext;
- MultiTimeframeContext;
- RiskActionGuardContext;
- `NumericPointSafetyValidator`.

P327 remains docs-only. It created no Java, no tests, no runtime read, no service wiring, and no dashboard wiring.

## P328 DTO Verification

P328 added `SourceTraceNumericSourceContextDTO` as a DTO-only Java skeleton.

The DTO only carries SourceTrace numeric source context fields.

It carries identity fields:

- `sourceTraceId`;
- `sourceOwner`;
- `sourceType`;
- `sourceContractId`;
- `symbol`;
- `market`;
- `timeframe`.

It carries numeric field fields:

- `numericFieldName`;
- `numericFieldRole`;
- `numericValue`;
- `numericValueLow`;
- `numericValueHigh`.

It carries source and downstream reference fields:

- `sourceRef`;
- `runtimeKlineContextRef`;
- `dataQualityContextRef`;
- `multiTimeframeContextRef`;
- `riskActionGuardRef`.

It carries safety / reason fields:

- `missingReason`;
- `blockedReason`;
- `trustedSource`;
- `reviewOnly`;
- `notTradeInstruction`;
- `manualReviewRequired`;
- `incompleteSafe`;
- `failClosed`.

It carries enum boundaries:

- `SourceType`;
- `NumericFieldRole`;
- `FreshnessStatus`;
- `SourceTraceStatus`.

The DTO includes `ORDER_BOOK_DIRECT` as a forbidden source type.

The DTO factories force:

- `reviewOnly = true`;
- `notTradeInstruction = true`;
- `manualReviewRequired = true`;
- `incompleteSafe = true`.

The DTO does not validate source trace completeness.

The DTO does not assemble source-owned candidate input.

The DTO does not calculate entry / stop / TP / RR.

The DTO does not connect any runtime provider, service, dashboard, external channel, order, execution, or auto-trading path.

## P329 Validator Verification

P329 added `SourceTraceNumericSourceReadModelValidator` as a validator-only Java skeleton.

The validator only validates `SourceTraceNumericSourceContextDTO`.

It checks safety flags:

- `reviewOnly`;
- `notTradeInstruction`;
- `manualReviewRequired`;
- `incompleteSafe`.

It checks fail-closed requirements:

- blocked DTO status requires `failClosed = true`;
- blocked DTO status requires non-empty `blockedReason`;
- any false safety flag is `BLOCKED_FAIL_CLOSED`.

It checks missing / blocked reason rules:

- incomplete status requires `missingReason`;
- blocked status requires `blockedReason`;
- missing reason failures remain safe and non-executable.

It checks SourceTrace identity fields:

- `sourceTraceId`;
- `sourceOwner`;
- `sourceType`;
- `sourceContractId`;
- `symbol`;
- `market`;
- `timeframe`.

It checks numeric source fields:

- `numericFieldName`;
- `numericFieldRole`;
- explicit numeric values for value roles;
- source-only reference can remain review-only without a numeric value when required refs exist.

It checks required refs:

- `sourceRef`;
- `observedAt`;
- `freshnessStatus`;
- `runtimeKlineContextRef`;
- `dataQualityContextRef`;
- `multiTimeframeContextRef`;
- `riskActionGuardRef`.

It checks source type boundaries:

- allowed source-owned types may continue when other requirements pass;
- forbidden source types fail closed;
- `ORDER_BOOK_DIRECT` fails closed.

It checks forbidden executable semantics in public status / reason / source strings.

Null, missing, stale, or unknown contexts remain `INCOMPLETE`.

Forbidden, untrusted, or executable-semantics contexts remain `BLOCKED_FAIL_CLOSED`.

The validator does not calculate `numericValue`.

The validator does not read market data.

The validator does not read real SourceTrace runtime data.

The validator does not connect assembler, service, external provider, order, execution, or auto-trading paths.
