# BACKEND-P291A Workflow Reset and Progress Source of Truth Pack

P291A is a risk A docs-only workflow correction pack.

This pack does not advance runtime features. Its purpose is to repair the project progress source of truth, capability matrix, review-only output policy, blocked capability registry, MVP roadmap, workflow rules, and drift guard checklist after repeated docs-only / authorization / closure / still-blocked loops.

## Why This Pack Exists

The project has accumulated many safe boundary documents and skeletons, but the business chain is not yet closed as a usable review-only MVP. Progress language also drifted: some docs treated open work as current state, some counted docs-only gates like production progress, and some blocked-list sections repeated without defining what review-only output remains allowed.

P291A resets that workflow.
