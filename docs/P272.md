## 4. Runtime Semantics

P272 is disabled-by-default, fail-closed, audit-only, review-only, no-message, no-provider, no-credential, and no-live-provider-call.

The policy may accept `OpportunityPushMessageEnvelopeDTO` as input, but it only evaluates whether the future provider channel remains disabled.

Every output preserves:

- `manualReviewRequired=true`
- `notTradeInstruction=true`
- `auditOnly=true`
- `providerChannelEnabled=false`
- `providerSelected=false`
- `providerCredentialRequired=false`

Missing, null, blank-symbol, or unsafe message envelope input fails closed.

Non-disabled-noop message envelope input remains incomplete / blocked / disabled and is never connected to a provider.

Safe disabled-noop message envelope input may only become a disabled no-op provider channel result.

Reasons and blocking reasons are preserved with defensive-copy list behavior.
