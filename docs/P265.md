## 4. Future Audit Queue Gate

Future audit queue work may only begin after a separate Java issue and PR authorize it.

The future audit queue must start:

- disabled-by-default
- fail-closed
- audit-only
- review-only
- no-message
- not a trade instruction
- without external provider dependency
- without delivery pipeline behavior unless separately authorized
- without scheduler / API / dashboard wiring

P266 may enter an audit queue no-op Java skeleton only if separately authorized by its issue.
