# P351 Source-Owned Candidate Integration Runtime Boundary Plan

## Package Type

P351 is an A-risk docs-only runtime boundary plan in the Readiness / Point Mainline.

It defines the boundary between the completed Source-Owned Candidate Integration Source Binding skeleton and any future runtime candidate generation work.

P351 adds no Java, no tests, no runtime wiring, no service, no dashboard, no external channel, no Push send, no order, no execution, and no auto-trading.

## Capability Movement

`SOURCE_OWNED_CANDIDATE_INTEGRATION_SOURCE_BINDING_ASSEMBLER_VERIFICATION -> SOURCE_OWNED_CANDIDATE_INTEGRATION_RUNTIME_BOUNDARY_PLAN`

This movement plans the runtime boundary only.

It does not make source-owned candidate integration runtime available.

It does not make candidate generation, point generation, final direction, push sending, or trading available.

## Runtime Boundary Definition

Runtime Candidate Generation is not point generation.

Runtime Candidate Generation is not trading execution.

Runtime Candidate Generation is not push sending.

Future runtime candidate generation may only output review-only runtime candidate context such as:

- runtime candidate integration status;
- source binding completeness summary;
- candidate unavailable reason;
- candidate blocked reason;
- candidate degraded reason;
- source trace refs;
- upstream context refs;
- `reviewOnly=true`;
- `notTradeInstruction=true`;
- `manualReviewRequired=true`;
- `incompleteSafe=true`.

Future runtime candidate generation must not directly output:

- executable entry;
- executable stop;
- executable TP;
- executable RR;
- final direction;
- order intent;
- execution intent;
- auto-trading action;
- push send payload;
- external channel message.

## Required Upstream Conditions

Future runtime candidate generation may continue only when all required upstream source bindings provide review-only, incomplete-safe, and fail-closed context:

- SourceTrace;
- RuntimeKlineContext;
- DataQualityContext;
- MultiTimeframeContext;
- RiskActionGuard;
- WatchlistPoolProof;
- SourceOwnedCandidateIntegrationSourceBinding.

Any missing upstream source binding must produce `INCOMPLETE`.

Any untrusted upstream source binding must produce `BLOCKED_FAIL_CLOSED`.

Any disabled upstream safety flag must produce `BLOCKED_FAIL_CLOSED`.

Any upstream executable semantics must produce `BLOCKED_FAIL_CLOSED`.

Any upstream block from RiskActionGuard or WatchlistPoolProof must produce `BLOCKED_FAIL_CLOSED`.

## Runtime Input Boundary

Future runtime input must come only from explicit source binding results.

Runtime candidate generation must not read:

- market data provider;
- latest price;
- latest close;
- dashboard text;
- AI prose;
- Watchlist service;
- rule config;
- audit table;
- account state;
- position state;

If only latest price, latest close, dashboard text, or AI prose exists, runtime candidate generation must return `INCOMPLETE`.

## Runtime Fail-Closed Conditions

Future runtime candidate generation must fail closed when:

- source binding validation is blocked;
- `allRequiredSourcesTrusted=false`;
- `allRequiredSourcesReviewOnly=false`;
- `allRequiredSourcesNotTradeInstruction=false`;
- `allRequiredSourcesManualReviewRequired=false`;
- `allRequiredSourcesIncompleteSafe=false`;
- RiskActionGuard is blocked;
- RiskActionGuard reports stampede;
- RiskActionGuard carries wick-only reverse semantics;
- RiskActionGuard carries liquidity-degraded one-shot exit semantics;
- WatchlistPoolProof is disabled;
- WatchlistPoolProof is empty;
- WatchlistPoolProof is non-member;
- WatchlistPoolProof is untrusted;
- Display Slots or the default home six assets are treated as Watchlist Pool Proof;
- external channel semantics appear;
- Push send semantics appear;
- order semantics appear;
- execution semantics appear;
- auto-trading semantics appear.

## Runtime Incomplete Conditions

Future runtime candidate generation must return `INCOMPLETE` when:

- source binding context is missing;
- source binding validation is incomplete;
- sourceBindingCompletenessScore is missing;
- sourceBindingCompletenessScore is too low;
- `anySourceIncomplete=true`;
- WatchlistPoolProof is stale;
- RuntimeKlineContext is stale;
- DataQualityContext is missing or insufficient;
- MultiTimeframeContext is unconfirmed;
- MultiTimeframeContext conflict is unresolved;
- missingReason is absent;
- only latest price, latest close, dashboard text, or AI prose exists.

## Watchlist Pool Boundary

Watchlist Pool is the maximum boundary for candidate / opportunity push eligibility.

Display Slots and default home assets are not Watchlist Pool Proof.

Default display does not mean push is allowed.

Assets outside the Watchlist Pool must not enter candidates.

P351 does not connect Watchlist service, read rule config, or read audit table.

## Risk Action Guard Boundary

High risk does not mean immediate stop, reverse, or open.

Strong reversal does not mean direct reverse.

Wick-only does not mean trend reversal.

Stampede state blocks opportunity push, reverse, and new open semantics.

Liquidity degradation must not become one-shot market exit semantics.

P351 does not generate executable risk actions.

## Disabled-By-Default Runtime Boundary

If future Java runtime work begins, it must be disabled by default.

By default it must:

- not participate in production decisions;
- not affect dashboard output;
- not send Push;
- not generate point proposals;
- not change existing decision results.

Future review-only preview must require explicit configuration.

When configuration is disabled, the runtime path must fail closed or no-op.

Even when enabled, it may only produce review-only runtime candidate status.
