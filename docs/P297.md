# P297 Score Input / Precheck Review-Only Slice

P297 belongs to the Evidence / Score Mainline（证据 / 评分主线）.

P297 continues from P296 review-only normalized evidence.

P297 adds a review-only score input / precheck skeleton so `ReviewOnlyNormalizedEvidenceDTO` can become a safe `ReviewOnlyScoreInputPrecheckDTO` for later review-only score assembly.

P297 is not real scoring.

P297 does not generate `ScoreItem`.

P297 does not calculate the eight score dimensions.

P297 does not generate trend, liquidity, macro, confidence, leverage, sentiment, or final score values.

P297 does not generate Candidate, Push, Readiness, point generation, entry, stop, TP, RR, order intent, execution intent, or auto-trading.

P297 does not connect `MarketQuoteClient` or `BinanceMarketQuoteClient`.

The user value is that review-only normalized evidence no longer stops at the normalized evidence object. It can now move into a score input / precheck skeleton for later review-only score assembly while remaining manual-review required and non-executable.
