# P262 Audit-Only Delivery Wiring Java Skeleton

## 1. 阶段定位

P262 新增 audit-only internal envelope skeleton。

P262 只把 `OpportunityPushDeliveryDecisionDTO` 转成内部审计信封对象，不执行 delivery，不发送消息，不持久化，不实现 queue。

P262 属于 B/C boundary Java audit-only wiring skeleton，不是生产接线，不是 external push execution，不是 Readiness，不是 point generation，不是交易路径。

## 2. P261 已完成基线

P261 已通过 PR #641 合并到 main，当前 main 基准为：

```text
4557733 BACKEND-P261 Push Channel No-Op Closure and Delivery Wiring Gate (#641)
```

P261 已定义：

- future wiring may connect internal review-only output to audit-only envelope only after separate authorization
- external providers remain blocked: Telegram / email / webhook / app notification / local notification
- scheduler / API / dashboard wiring remains blocked
- runtime / live / external data reads remain blocked
- Readiness / point generation / entry-stop-TP-RR / order / execution / auto-trading remain blocked
- Display Slots / 默认六币不能作为 batch universe

- Risk Action Guard 必须位于 delivery 前
- 踩踏状态禁止机会推送
- 插针不等于趋势反转
- 强反转不等于直接反手

## 4. Java Skeleton 语义

P262 assembler 可以引用 `OpportunityPushDeliveryDecisionDTO` 作为输入，但不得执行 delivery。

所有输出必须保持：

- review-only / fail-closed
- `manualReviewRequired=true`
- `notTradeInstruction=true`
- `auditOnly=true`
- `externalPushSent=false`
- `deliveryAttempted=false`
- `deliveryEnabled=false`
- `persisted=false`
- `queued=false`
- `readinessUpgraded=false`
- `tradingActionCreated=false`
- `entryStopTpRrGenerated=false`

safe review-only delivery decision 最多只能生成 audit-only internal envelope。

missing / null / unsafe delivery decision 必须 fail closed。

non-review-only delivery decision 只能保持 incomplete / blocked / disabled，绝不能 delivery。

reasons / blockingReasons 必须保留，list 字段必须 defensive copy。

## 6. 结论

P262 只新增 audit-only internal envelope Java skeleton。

External channel、message sending、persistence、queue、Readiness、point generation 和交易路径仍未实现，后续必须另开授权门。
