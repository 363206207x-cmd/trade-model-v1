## Future Runtime Validator Position

A future validator may be named:

`SourceOwnedCandidateIntegrationRuntimeCandidateValidator`

The validator may only verify that `SourceOwnedCandidateIntegrationRuntimeCandidateDTO` is safe.

It may validate:

- runtime status compliance;
- forced safety flags;
- required field presence;
- incomplete / blocked / degraded / review-only state and reason consistency;
- forbidden executable semantics in public string and list fields.

It must not:

- read market data;
- read latest price;
- read latest close;
- read Watchlist service;
- read rule config;
- read audit table;
- call service;
- generate candidate runtime;
- generate point proposal;
- generate final direction;
- generate push payload;
- generate trading action.

## Recommended ValidationStatus

Future `ValidationStatus` values should be:

- `INCOMPLETE`;
- `BLOCKED_FAIL_CLOSED`;
- `REVIEW_ONLY_RUNTIME_CANDIDATE_VALID`;
- `REVIEW_ONLY_RUNTIME_CANDIDATE_DEGRADED`.

`REVIEW_ONLY_RUNTIME_CANDIDATE_VALID` is not a buy signal.

`REVIEW_ONLY_RUNTIME_CANDIDATE_VALID` is not a sell signal.

`REVIEW_ONLY_RUNTIME_CANDIDATE_VALID` is not a final direction.

`REVIEW_ONLY_RUNTIME_CANDIDATE_VALID` is not a point.

`REVIEW_ONLY_RUNTIME_CANDIDATE_VALID` is not push sending.

`REVIEW_ONLY_RUNTIME_CANDIDATE_VALID` is not a trade action.

## Base Safety Validation Rules

Future Runtime Validator checks must include:

- context null -> `INCOMPLETE`;
- candidateRuntimeStatus null -> `INCOMPLETE`;
- `reviewOnly` must be true, otherwise `BLOCKED_FAIL_CLOSED`;
- `notTradeInstruction` must be true, otherwise `BLOCKED_FAIL_CLOSED`;
- `manualReviewRequired` must be true, otherwise `BLOCKED_FAIL_CLOSED`;
- `incompleteSafe` must be true, otherwise `BLOCKED_FAIL_CLOSED`;
- `failClosed` may be true only for `BLOCKED_FAIL_CLOSED`, otherwise `BLOCKED_FAIL_CLOSED`;
- sourceOwnedCandidateIntegrationSourceBindingRef is required;
- sourceOwnedCandidateIntegrationValidationStatus is required;
- sourceTraceRefs are required;
- runtimeKlineContextRef is required;
- dataQualityContextRef is required;
- multiTimeframeContextRef is required;
- riskActionGuardContextRef is required;
- watchlistPoolProofContextRef is required;
- observedAt is required;
- missingReason or candidateUnavailableReason is required for `INCOMPLETE`;
- blockedReason or candidateBlockedReason is required for `BLOCKED_FAIL_CLOSED`;
- candidateDegradedReason or degradedReasons is required for degraded output.

## INCOMPLETE Rules

Future Runtime Validator must return `INCOMPLETE` when:

- context is null;
- candidateRuntimeStatus is null;
- sourceOwnedCandidateIntegrationSourceBindingRef is missing;
- sourceOwnedCandidateIntegrationValidationStatus is missing;
- sourceBindingCompletenessScore is missing;
- sourceBindingCompletenessScore is too low;
- sourceTraceRefs are missing;
- RuntimeKlineContext is missing;
- RuntimeKlineContext is stale;
- DataQualityContext is missing;
- DataQualityContext is insufficient;
- MultiTimeframeContext is unconfirmed;
- MultiTimeframeContext conflict is unresolved;
- WatchlistPoolProof is stale;
- `anySourceIncomplete=true`;
- status is `INCOMPLETE` but both missingReason and candidateUnavailableReason are missing;
- only latest price exists;
- only latest close exists;
- only dashboard text exists;
- only AI prose exists.

## BLOCKED_FAIL_CLOSED Rules

Future Runtime Validator must return `BLOCKED_FAIL_CLOSED` when:

- candidateRuntimeStatus is `BLOCKED_FAIL_CLOSED`;
- sourceOwnedCandidateIntegrationValidationStatus is `BLOCKED_FAIL_CLOSED`;
- `allRequiredSourcesTrusted=false`;
- `allRequiredSourcesReviewOnly=false`;
- `allRequiredSourcesNotTradeInstruction=false`;
- `allRequiredSourcesManualReviewRequired=false`;
- `allRequiredSourcesIncompleteSafe=false`;
- `anySourceBlocked=true`;
- `riskActionGuardBlocked=true`;
- `riskActionGuardStampede=true`;
- RiskActionGuard wick-only reverse semantics appear;
- RiskActionGuard liquidity-degraded one-shot exit semantics appear;
- `watchlistPoolMember=false`;
- `watchlistPoolProofFresh=false` and cannot safely degrade to `INCOMPLETE`;
- WatchlistPoolProof disabled / empty / non-member / untrusted semantics appear;
- Display Slots or default home six assets are treated as Watchlist Pool Proof;
- external channel / Push send / order / execution / auto-trading semantics appear;
- DTO fields contain forbidden executable semantics.

## DEGRADED Rules

Future Runtime Validator may return `REVIEW_ONLY_RUNTIME_CANDIDATE_DEGRADED` only when:

- candidateRuntimeStatus is `REVIEW_ONLY_RUNTIME_CANDIDATE_DEGRADED`;
- `anySourceDegraded=true`;
- candidateDegradedReason or degradedReasons are present;
- all safety flags are true;
- no blocked condition exists;
- no executable semantics appear.

If `anySourceDegraded=true` and no degraded reason exists, the validator must return `INCOMPLETE`.

It must not silently pass degraded input.

It must not upgrade degraded input to full review-only valid.

## Watchlist Pool Boundary

Watchlist Pool is the maximum boundary for candidates and opportunity push eligibility.

Display Slots and the default six home assets are not Watchlist Pool Proof.

Default display does not mean push eligibility.

An asset outside Watchlist Pool must not enter candidate output.

P355 does not connect Watchlist service, rule config, or audit table reads.

## Risk Action Guard Boundary

High risk does not mean immediate stop-loss.

High risk does not mean immediate reverse.

High risk does not mean immediate new position.

Strong reversal does not mean direct reverse.

Wick-only does not mean trend reversal.

Stampede state forbids opportunity push, reverse, and new position.

Liquidity degradation forbids one-shot market-cut semantics.

P355 does not generate executable risk actions.
