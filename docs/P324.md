# P324 Source-owned Numeric Point Candidate Assembler Java Skeleton

## Purpose

P324 belongs to the Readiness / Point Mainline.

P324 follows P323 `SOURCE_OWNED_NUMERIC_POINT_CANDIDATE_ASSEMBLER_PLAN`.

P324 adds a minimal plain Java `SourceOwnedNumericPointCandidateAssembler` skeleton and targeted tests.

The assembler converts source-owned input context into `ReviewOnlyNumericPointProposalAssembler.AssemblyInput`, then calls `ReviewOnlyNumericPointProposalAssembler` so `NumericPointSafetyValidator` remains mandatory.

P324 is not point generation, not service wiring, not dashboard runtime integration, not external push, and not order / execution / auto-trading.

## What P324 Adds

P324 adds:

- `src/main/java/org/example/trademodel/assembler/point/SourceOwnedNumericPointCandidateAssembler.java`;
- `src/test/java/org/example/trademodel/assembler/point/SourceOwnedNumericPointCandidateAssemblerTest.java`.

The assembler exposes:

- `assemble(SourceOwnedNumericPointContext context)`;
- nested `SourceOwnedNumericPointContext`;
- nested `SourceOwnedEntryContext`;
- nested `SourceOwnedStopContext`;
- nested `SourceOwnedTakeProfitContext`;
- nested `SourceOwnedRiskRewardContext`;
- nested `SourceOwnedAssembledNumericPoint`.

`SourceOwnedAssembledNumericPoint` carries:

- `ReviewOnlyNumericPointProposalAssembler.AssembledReviewOnlyNumericPoint assembled`;
- `ReviewOnlyNumericPointProposalDTO proposal`;
- `NumericPointSafetyValidator.ValidationResult validationResult`.

## Assembly Boundary

The assembler only moves source-owned fields that are already present in input context.

It does not calculate entry, stop, TP, RR, final direction, or any executable signal.

It does not infer values from latest price, latest close, volatility, score, label, AI prose, dashboard text, or market data.

It does not provide defaults for missing point values.

It does not decide whether to trade.

It does not send messages.

It does not call external APIs.

## Status Handling

The assembler maps source-owned context into P322 explicit assembly input:

- null context -> `INCOMPLETE`;
- any untrusted entry / stop / TP / RR source -> `BLOCKED_FAIL_CLOSED`;
- requested `BLOCKED_FAIL_CLOSED` -> blocked;
- requested `REVIEW_ONLY_NUMERIC_POINT_DEGRADED` -> degraded;
- requested `REVIEW_ONLY_NUMERIC_POINT_CANDIDATE` -> candidate when refs and point fields are present;
- missing TP or RR with explicit missing reason -> degraded;
- missing entry or stop source refs -> `INCOMPLETE`;
- any unsupported status -> `INCOMPLETE`.

Every result goes through `ReviewOnlyNumericPointProposalAssembler` and then `NumericPointSafetyValidator`.

## Source-owned Point Field Boundary

The assembler can carry explicit source-owned:

- entry context;
- stop context;
- TP context list;
- RR context.

These fields are moved only. They may be null.

Missing fields are resolved by validator status: `INCOMPLETE`, degraded review-only, or blocked fail-closed.

The assembler does not inspect行情, does not judge direction, and does not decide execution.

## Trusted Source Boundary

Every source-owned entry / stop / TP / RR context carries `trustedSource`.

If any source-owned sub-context has `trustedSource = false`, P324 produces `BLOCKED_FAIL_CLOSED` with `SOURCE_UNTRUSTED`.

Untrusted sources must never become candidates or degraded candidates.

## Validation Scope

The targeted test verifies:

- null context remains incomplete;
- complete source-owned context validates as review-only candidate;
- explicit entry / stop / TP / RR values are preserved without calculation;
- missing entry / stop source refs remain incomplete;
- missing TP or RR with explicit reason degrades;
- missing TP or RR without reason remains incomplete;
- missing SourceTrace / RuntimeKlineContext / DataQuality / MultiTimeframe / RiskActionGuard / Watchlist Pool refs remain incomplete;
- untrusted entry / stop / TP / RR sources fail closed;
- forbidden executable semantics fail closed;
- `ReviewOnlyNumericPointProposalAssembler` is called;
- null sub-contexts do not throw;
- assembler has no Spring annotations, provider clients, service/controller/mapper/repository/scheduler refs, external channel refs, or order / execution / auto-trading refs.
