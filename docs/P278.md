# P278 Real Scan Input Contract DTO Authorization Gate

P278 is a docs-only authorization gate after P277.

P277 merged as `82d5313` (`BACKEND-P277 Real Scan Contract Audit and Market-Read Boundary Plan (#673)`). P278 does not implement the real scan input contract DTO. It only defines what a future DTO skeleton may contain, what it must exclude, and which safety defaults must remain in place before any real scan input can be considered eligible.

## Scope

- `PHASE_P278_REAL_SCAN_INPUT_CONTRACT_DTO_AUTHORIZATION_GATE.md`

- `PHASE_P278_SCORE_CANDIDATE_PUSH_STILL_BLOCKED.md`
- `PHASE_P278_READINESS_POINT_GENERATION_STILL_BLOCKED.md`

P279 may add a real scan input contract DTO / enum / targeted test only if separately authorized. P279 must remain DTO-only and targeted-test-only unless a later issue explicitly grants more.

## Future DTO Field Plan

A future DTO may include:

- symbol
- source
- requested scan reason
- Watchlist Pool membership proof
- watchlist config version
- requested timeframe list
- scan timestamp
- market-read requirement flags
- data availability expectations
- stale or missing input behavior
- risk blockers
- review-only safety flags

This is only a field plan. P278 does not add Java, DTOs, enums, tests, service wiring, scheduler wiring, API wiring, dashboard wiring, market-read wiring, or runtime data reads.

## Safety Defaults

The future DTO must preserve review-only / fail-closed / audit-only semantics where applicable.

Mandatory defaults:

- `manualReviewRequired=true`
- `notTradeInstruction=true`

The future DTO must not contain fields for trade action, order, execution, entry, stop, take profit, RR, provider, external channel, message sending, or readiness.

Watchlist Pool proof is required before any future scan input can be considered eligible. Display Slots / 默认六币 cannot be scan universe or batch universe.

## Still Blocked

P278 does not authorize:

- `MarketQuoteClient` / `BinanceMarketQuoteClient` wiring
- runtime/live/external data read
- real scan loop
- production ScanScore computation
- Candidate production workflow
- Opportunity Push execution
- scheduler/API/dashboard wiring
- external channel behavior / provider credentials / live provider call / message rendering / sending
- Readiness / point generation / entry-stop-TP-RR / order / execution / auto-trading

Risk Action Guard must remain before delivery / Push / Readiness.
