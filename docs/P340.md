## MultiTimeframeContext Binding Boundary

MultiTimeframeContext source binding is the future review-only alignment and conflict evidence layer after DataQualityContext and before RiskActionGuard.

It may carry only explicit input fields:

- SourceTrace refs;
- RuntimeKlineContext ref;
- DataQualityContext ref;
- primary timeframe;
- timeframe refs;
- timeframe scores;
- timeframe directions as source-owned labels, not final direction;
- timeframe weights;
- aligned / conflicted / missing / stale timeframe lists;
- dominant direction as explicit source-owned context text, not final direction;
- alignment score;
- conflict score;
- weighted agreement score;
- threshold pass flags;
- missing / degraded / blocked reasons.

It does not calculate scores. It does not read market data. It does not read latest price or latest close. It does not decide final direction. It does not derive point values.
