# P344 Source-Owned Candidate Integration Source Binding Plan

## Package Type

P344 is an A-risk docs-only plan in the Readiness / Point Mainline.

It is the source binding plan that follows P343 Source-Owned Candidate Integration Boundary Plan.

P344 is not Java implementation. It is not runtime wiring. It is not source-owned candidate integration runtime. It is not a candidate generator. It is not a point generator. It is not a push sender. It is not a trading execution layer.

P344 is L0 only:

- L0 Source Binding Plan: complete in this package;
- L1 DTO: not started;
- L2 Validator: not started;
- L3 Assembler: not started;
- L4 Verification: not started;
- L5 Internal wiring: not started;
- L6 Dashboard preview: not started;
- L7 Runtime-safe usable: not started.

P344 does not raise Production Runtime Progress.

## Capability Movement

`SOURCE_OWNED_CANDIDATE_INTEGRATION_BOUNDARY_PLAN -> SOURCE_OWNED_CANDIDATE_INTEGRATION_SOURCE_BINDING_PLAN`

This movement only defines the future source binding shape for source-owned candidate integration.

It does not implement DTO, validator, assembler, source-owned candidate runtime, internal preview, dashboard runtime, push, or trading behavior.

## Source Binding Position

Future Source-Owned Candidate Integration Source Binding sits between the completed source binding skeleton families and any future source-owned candidate integration DTO / validator / assembler.

The intended future chain remains:

`SourceTrace + RuntimeKlineContext + DataQualityContext + MultiTimeframeContext + RiskActionGuard + WatchlistPoolProof -> Source-Owned Candidate Integration Source Binding -> future source-owned candidate integration validator / assembler -> SourceOwnedNumericPointCandidateAssembler -> ReviewOnlyNumericPointProposalAssembler -> NumericPointSafetyValidator`

The source binding layer may only summarize explicit upstream source binding inputs.

It must not read runtime providers, database state, service state, dashboard text, latest price, latest close, or external channels.

## Inherited Fail-Closed Conditions

Future source binding must inherit all P343 fail-closed boundaries.

It must return `BLOCKED_FAIL_CLOSED` when any of the following occurs:

- any upstream source binding is untrusted;
- any upstream safety flag is disabled;
- RiskActionGuard is blocked;
- RiskActionGuard reports stampede;
- RiskActionGuard sees wick-only reverse semantics;
- RiskActionGuard sees liquidity-degraded one-shot exit semantics;
- WatchlistPoolProof is disabled;
- WatchlistPoolProof is empty;
- WatchlistPoolProof reports non-member asset;
- WatchlistPoolProof is stale / untrusted;
- Display Slots / default six home assets are treated as Watchlist Pool Proof;
- external channel is attempted;
- Push send is attempted;
- order / execution / auto-trading semantics are attempted.

Fail-closed output must not produce usable candidate output.

## Incomplete-Safe Conditions

Future source binding must return `INCOMPLETE` when:

- required refs are missing;
- any upstream binding is incomplete;
- source binding completeness summary is missing;
- sourceBindingCompletenessScore is missing;
- sourceBindingCompletenessScore is too low to pass safely;
- any required source binding has stale context without fail-closed reason;
- any required missing reason is absent;
- only latest price exists;
- only latest close exists;
- only display slot state exists;
- only dashboard text exists;
- only AI prose exists.

Incomplete output must remain review-only and manual-review required.

## Watchlist Pool Boundary

Watchlist Pool remains the maximum boundary for candidate / opportunity-push eligibility.

The future source binding must preserve:

- Watchlist Pool is the maximum candidate boundary;
- Display Slots are not Watchlist Pool Proof;
- default six home assets are not Watchlist Pool Proof;
- default display does not authorize push candidacy;
- an asset outside Watchlist Pool cannot enter candidate integration;
- disabled / empty / non-member / stale / untrusted WatchlistPoolProof cannot pass.

P344 does not connect Watchlist service, does not read rule config, and does not read audit tables.

## Risk Action Guard Boundary

Risk Action Guard remains a mandatory source binding before candidate integration can become review-ready.

Future source binding must preserve:

- high risk does not mean immediate stop;
- high risk does not mean immediate reverse;
- high risk does not mean immediate open;
- strong reversal does not mean direct reverse;
- wick-only does not mean trend reversal;
- stampede state blocks opportunity push, reverse, and new open semantics;
- liquidity degradation must not become one-shot market cut semantics.

RiskActionGuard is an action review boundary, not an execution engine.
