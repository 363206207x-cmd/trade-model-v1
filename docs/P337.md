## Safety Rules / 安全规则

The validator requires:

- `reviewOnly = true`;
- `notTradeInstruction = true`;
- `manualReviewRequired = true`;
- `incompleteSafe = true`.

validator 要求：

- `reviewOnly = true`；
- `notTradeInstruction = true`；
- `manualReviewRequired = true`；
- `incompleteSafe = true`。

Any disabled safety flag returns `BLOCKED_FAIL_CLOSED`.

任何 safety flag 被关闭都返回 `BLOCKED_FAIL_CLOSED`。

`BLOCKED_FAIL_CLOSED` DTO status must have `failClosed = true` and non-blank blocked reason.

`BLOCKED_FAIL_CLOSED` DTO status 必须有 `failClosed = true` 和非空 blocked reason。

`INCOMPLETE` must remain safe and non-executable.

`INCOMPLETE` 必须保持安全且不可执行。

## Runtime State Rules / 运行状态规则

The validator keeps runtime state review-only:

- stale / unknown freshness -> `INCOMPLETE`;
- wick-only / unknown wick -> `INCOMPLETE`;
- severe gap -> `BLOCKED_FAIL_CLOSED`;
- unknown gap -> `INCOMPLETE`;
- severely degraded liquidity -> `INCOMPLETE` unless executable-attempt blocked reason exists, then `BLOCKED_FAIL_CLOSED`;
- unknown liquidity -> `INCOMPLETE`;
- suspected stampede -> `INCOMPLETE`;
- confirmed stampede -> `BLOCKED_FAIL_CLOSED`;
- unknown stampede -> `INCOMPLETE`.

validator 保持 runtime state 只读：

- stale / unknown freshness -> `INCOMPLETE`；
- wick-only / unknown wick -> `INCOMPLETE`；
- severe gap -> `BLOCKED_FAIL_CLOSED`；
- unknown gap -> `INCOMPLETE`；
- severely degraded liquidity -> `INCOMPLETE`，如果 blocked reason 指向 executable attempt，则 `BLOCKED_FAIL_CLOSED`；
- unknown liquidity -> `INCOMPLETE`；
- suspected stampede -> `INCOMPLETE`；
- confirmed stampede -> `BLOCKED_FAIL_CLOSED`；
- unknown stampede -> `INCOMPLETE`。

Wick-only is not trend reversal.

wick-only 不是趋势反转。

Strong reversal is not direct reverse.

strong reversal 不是直接反手。

High risk is not an immediate stop.

高风险不等于立即止损。

Degraded liquidity is not a one-shot market cut.

流动性恶化不等于一次性市价砍仓。

## SourceTrace Ref Boundary / SourceTrace 引用边界

The validator requires existing SourceTrace refs.

validator 要求已有 SourceTrace refs。

## Forbidden Semantics / 禁用语义

The validator fail-closes if public status / reason / market data ref / SourceTrace refs contain executable semantics.

如果公开 status / reason / market data ref / SourceTrace refs 含可执行交易语义，validator fail-closed。

This remains a safety check, not a trading recommendation.

这只是安全校验，不是交易建议。
