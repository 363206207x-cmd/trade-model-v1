# P290 MarketReadRequestGuardValidator Java Skeleton

P290 is a B Validator Java/test pack for Issue #698.

P290 implements the `MarketReadRequestGuardValidator` Java skeleton authorized by P289.

## Scope

P290 adds a pure validator skeleton that only validates `MarketReadRequestDTO`.

The validator returns a `MarketReadRequestGuardValidationResult` that can only express:

- blocked;
- review-only;
- fail-closed;
- validation reasons;
- preserved blocking reasons;
- preserved risk blockers;
- manual review required;
- not trade instruction.

## Validation Rules

The validator fails closed when:

- request is null;
- `sourceContractId` is missing;
- `watchlistPoolProof` is missing;
- `requestedTimeframes` are missing;
- `scanTimestamp` is missing;
- `stalePolicy` is missing or not `FAIL_CLOSED`;
- `missingDataPolicy` is missing or not `FAIL_CLOSED`;
- `reviewOnly` is not true;
- `notTradeInstruction` is not true.

## Boundary Rules

Watchlist Pool remains the scan candidate boundary.

Display Slots / 默认六币 are not the scan universe, not the batch universe, not the push universe, and not the Watchlist Pool proof source.

Risk Action Guard must remain before delivery / Push / Readiness.
