# P296 Evidence Normalization Review-Only Slice

P296 belongs to the Evidence / Score Mainline（证据 / 评分主线）.

P296 continues from P295 review-only Evidence / Score entry.

P296 adds a review-only evidence normalization skeleton so `ReviewOnlyEvidenceScoreEntryDTO` can become a safe `ReviewOnlyNormalizedEvidenceDTO` for later score input / precheck work.

P296 is not real evidence generation.

P296 does not persist evidence and does not write DB state.

P296 does not calculate the eight score dimensions.

P296 does not generate Candidate, Push, Readiness, point generation, entry, stop, TP, RR, order intent, execution intent, or auto-trading.

P296 does not connect `MarketQuoteClient` or `BinanceMarketQuoteClient`.

The user value is that the review-only Evidence / Score entry no longer stops at the entry envelope. It can now move into a normalized evidence skeleton for later score input precheck / review-only score assembly while remaining manual-review required and non-executable.
