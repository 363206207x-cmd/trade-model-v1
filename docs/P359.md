# P359 Source-Owned Candidate Integration Runtime Assembler / Orchestrator Java Skeleton

## Package Type

P359 is a B-risk Java/test Runtime Assembler skeleton in the Readiness / Point Mainline.

It adds a plain Java `SourceOwnedCandidateIntegrationRuntimeCandidateAssembler` and targeted assembler tests.

P359 does not add service, internal wiring, dashboard runtime, external channel, Push send, order, execution, or auto-trading.

## Scope

P359 completes only:

- L3 Runtime Assembler / Orchestrator skeleton;

- status, progress, and capability documentation updates.

P359 does not complete:

- L4 Runtime Verification;
- L5 Internal wiring;
- L6 Dashboard preview;
- L7 Runtime-safe usable.

## Implemented Java Boundary

`SourceOwnedCandidateIntegrationRuntimeCandidateAssembler` is a plain Java explicit-input assembler.

It can only:

- receive explicit `RuntimeAssemblyInput`;
- move explicit input fields into `SourceOwnedCandidateIntegrationRuntimeCandidateDTO`;
- choose the DTO factory by explicit requested runtime status:
  - `incomplete(...)`;
  - `blockedFailClosed(...)`;
  - `degraded(...)`;
  - `reviewOnly(...)`;
- call `SourceOwnedCandidateIntegrationRuntimeCandidateValidator.validate(...)` immediately after DTO construction;
- return `AssembledSourceOwnedCandidateIntegrationRuntimeCandidate` containing context plus validation result.

It cannot:

- read market data;
- read latest price or latest close;
- read Watchlist service, rule config, audit table, DB, dashboard text, or AI prose;
- call service;
- generate point proposal;
- generate entry, stop, TP, RR, final direction, push payload, or trading action;
- skip validator;
- change a failed DTO into a passing DTO after validation.

## Safety Rules

P359 preserves:

- `reviewOnly=true`;
- `notTradeInstruction=true`;
- `manualReviewRequired=true`;
- `incompleteSafe=true`;
- fail-closed handling for blocked states.

The assembler uses safe fallback reasons for missing input, unsupported runtime status, missing incomplete reason, missing blocked reason, and missing degraded reason.

It does not compute status, trade direction, numeric point values, or runtime candidate decisions.
