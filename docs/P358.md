## Future Class Position

The recommended minimal future implementation name is:

`SourceOwnedCandidateIntegrationRuntimeCandidateAssembler`

If later orchestration needs are broader than explicit DTO assembly, the name may become:

`SourceOwnedCandidateIntegrationRuntimeCandidateOrchestrator`

P358 recommends starting with the smaller assembler name.

The future assembler / orchestrator may only:

- receive explicit `SourceOwnedCandidateIntegrationRuntimeAssemblyInput`;
- move explicit input fields into `SourceOwnedCandidateIntegrationRuntimeCandidateDTO`;
- choose the DTO factory: `incomplete(...)`, `blockedFailClosed(...)`, `degraded(...)`, or `reviewOnly(...)`;
- call `SourceOwnedCandidateIntegrationRuntimeCandidateValidator.validate(...)`;
- return DTO + validation result;
- preserve review-only, not-trade-instruction, manual-review-required, incomplete-safe, and fail-closed boundaries.

It must not:

- read market data;
- read latest price;
- read latest close;
- read Watchlist service;
- read rule config;
- read audit table;
- read DB;
- call service;
- generate point proposal;
- generate final direction;
- generate push payload;
- generate trading action;
- modify a failed DTO into a valid DTO after validation;
- skip validator.

## DTO Factory Selection Rules

The future assembler / orchestrator should choose factories by explicit `requestedRuntimeStatus` or explicit missing / blocked / degraded state:

- input null -> DTO `incomplete(...)`;
- requestedRuntimeStatus = `INCOMPLETE` -> DTO `incomplete(...)`;
- requestedRuntimeStatus = `BLOCKED_FAIL_CLOSED` -> DTO `blockedFailClosed(...)`;
- requestedRuntimeStatus = `REVIEW_ONLY_RUNTIME_CANDIDATE_DEGRADED` -> DTO `degraded(...)`;
- requestedRuntimeStatus = `REVIEW_ONLY_RUNTIME_CANDIDATE` -> DTO `reviewOnly(...)`;
- unsupported or null requestedRuntimeStatus -> DTO `incomplete(...)`.

The assembler must not compute trading direction.

The assembler must not generate points.

The assembler must not force degraded or incomplete input into review-only success.

The assembler must not downgrade blocked fail-closed input into review-only.

The assembler must not silently drop missing, blocked, or degraded reasons.

## Validator Invocation Rules

The future assembler / orchestrator must:

- call `SourceOwnedCandidateIntegrationRuntimeCandidateValidator.validate(...)` immediately after DTO construction;
- use `new SourceOwnedCandidateIntegrationRuntimeCandidateValidator()` by default;
- allow test-only validator injection so tests can prove validator invocation;
- never skip validator;
- never modify a DTO after validator failure to make it pass;
- never swallow validation reasons;
- return the validation result unchanged.

## INCOMPLETE Assembly Rules

Future assembly must output an `INCOMPLETE` DTO or validation result when:

- input is null;
- requestedRuntimeStatus is null or unsupported;
- sourceOwnedCandidateIntegrationSourceBindingRef is missing;
- sourceOwnedCandidateIntegrationValidationStatus is missing;
- sourceBindingCompletenessScore is missing;
- sourceBindingCompletenessScore is too low;
- sourceTraceRefs are missing;
- runtimeKlineContextRef is missing;
- `runtimeKlineStale=true`;
- dataQualityContextRef is missing;
- `dataQualityPassed=false` or null;
- multiTimeframeContextRef is missing;
- `multiTimeframeConfirmed=false` or null;
- `watchlistPoolProofFresh=false` and can safely degrade to `INCOMPLETE`;
- `anySourceIncomplete=true`;
- missingReason or candidateUnavailableReason is missing;
- only latest price, latest close, dashboard text, or AI prose exists.

## BLOCKED_FAIL_CLOSED Assembly Rules

Future assembly must output a `BLOCKED_FAIL_CLOSED` DTO or validation result when:

- requestedRuntimeStatus = `BLOCKED_FAIL_CLOSED`;
- sourceOwnedCandidateIntegrationValidationStatus = `BLOCKED_FAIL_CLOSED`;
- `allRequiredSourcesTrusted=false`;
- `allRequiredSourcesReviewOnly=false`;
- `allRequiredSourcesNotTradeInstruction=false`;
- `allRequiredSourcesManualReviewRequired=false`;
- `allRequiredSourcesIncompleteSafe=false`;
- `anySourceBlocked=true`;
- `riskActionGuardBlocked=true`;
- `riskActionGuardStampede=true`;
- RiskActionGuard wick-only reverse semantics appear;
- RiskActionGuard liquidity-degraded one-shot exit semantics appear;
- `watchlistPoolMember=false`;
- WatchlistPoolProof disabled / empty / non-member / untrusted semantics appear;
- Display Slots or the default six home assets are treated as Watchlist Pool Proof;
- external channel / Push send / order / execution / auto-trading semantics appear;
- DTO fields contain forbidden executable semantics.

## DEGRADED Assembly Rules

Future assembly may output `REVIEW_ONLY_RUNTIME_CANDIDATE_DEGRADED` only when:

- requestedRuntimeStatus = `REVIEW_ONLY_RUNTIME_CANDIDATE_DEGRADED`;
- `anySourceDegraded=true`;
- candidateDegradedReason or degradedReasons are present;
- all safety flags are true;
- no blocked condition exists;
- no executable semantics appear.

If `anySourceDegraded=true` and no degraded reason exists, the assembler must return `INCOMPLETE`.

The assembler must not upgrade degraded input to full review-only valid.

## Watchlist Pool Boundary

Watchlist Pool is the maximum boundary for candidate and opportunity-push eligibility.

Display Slots and the default six home assets are not Watchlist Pool Proof.

Default display does not mean push is allowed.

Assets outside Watchlist Pool must not enter the candidate set.

P358 does not connect Watchlist service, rule config, or audit table.

## Risk Action Guard Boundary

High risk does not mean immediate stop, immediate reverse, or immediate open.

Strong reversal does not mean direct reverse.

Wick-only does not mean trend reversal.

Stampede state forbids opportunity push, reverse, and new open.

Liquidity degradation forbids one-shot market cut semantics.

P358 does not generate executable risk actions.

## Disabled-By-Default Boundary

Future runtime assembler / orchestrator work must remain:

- disabled by default;
- not part of production decisions by default;
- unable to affect dashboard by default;
- unable to send Push by default;
- unable to generate point proposal by default;
- unable to change existing decision result by default.

When configuration is off, future runtime must fail closed or no-op.

When configuration is on, future runtime may only output review-only runtime candidate status.
