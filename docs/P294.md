# P294 Review-Only MarketRead Output And Scan Output Slice

P294 belongs to the Market Read Mainline（行情读取主线）.

It continues from P293 MarketReadRequest Review-Only Output Assembler（P293 行情读取请求只读输出组装器）.

## Scope

P294 adds a review-only scan output skeleton.

The new slice turns:

- `MarketReadReviewOnlyOutputDTO`

into:

- `MarketReadReviewOnlyScanOutputDTO`

through `MarketReadReviewOnlyScanOutputAssembler`.

## User Value

Before P294, MarketReadRequest review output was readable but still sat at the request-validation output layer.

After P294, that output can become a review-only scan output skeleton for later Evidence / Score entry points.

This makes the chain easier to inspect without introducing real market data, production scan output, score, Candidate, Push, Readiness, point generation, or trading behavior.

## Boundaries

P294 is not production market read.

P294 does not connect:

- `MarketQuoteClient`
- `BinanceMarketQuoteClient`
- provider client
- runtime/live/external data read
- controller / endpoint / API
- mapper / repository / DB write
- scheduler

P294 does not generate:

- production scan output
- Score
- Evidence
- Candidate / Candidate Attention / Promote To Home
- Opportunity Push
- Readiness
- point generation
- entry / stop / TP / RR
- order / execution / auto-trading

## Capability Movement

P294 moves the MarketRead chain from `REVIEW_ONLY_OUTPUT_SKELETON` to `REVIEW_ONLY_SCAN_OUTPUT_SKELETON`.

It remains review-only, manual-review required, non-executable, and not a trade instruction.
