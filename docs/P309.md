# P309 Source-owned Review-only Point Proposal Skeleton

## Purpose

P309 belongs to the Readiness / Point Mainline.

It continues from P308, where `ReviewOnlyPointBoundaryGateDTO` established a review-only point boundary gate after the review-only readiness gate.

P309 adds a source-owned review-only point proposal skeleton. The new output can carry point proposal fields, but the assembler must not invent entry, stop, TP, or RR values.

## What P309 Adds

- `ReviewOnlyPointProposalDTO`
- `ReviewOnlyPointProposalAssembler`
- targeted tests for source-owned, incomplete-safe, non-executable point proposal behavior

The point proposal DTO may carry nullable fields for:

- proposed entry / entry zone
- proposed stop / stop zone
- proposed take-profit / take-profit plan
- proposed RR / risk reward

Those fields remain nullable and incomplete-safe. They are not executable trading instructions.

## What P309 Is Not

P309 is not executable point generation.

P309 does not generate executable entry / stop / TP / RR.

P309 does not generate a final direction, long-short signal, order intent, execution intent, order API call, execution API call, or auto-trading action.

P309 does not authorize external channels and does not send Telegram, email, webhook, app notification, local notification, or any external message.

P309 does not bypass recheck or the Risk Action Guard.

## Source-Owned Requirement

Point proposal fields require source-owned trace and runtime context before they can be populated in a future package.

If source trace, runtime kline context, data quality, or multi-timeframe confirmation is missing, the output must remain `INCOMPLETE`.

P309 preserves:

- `sourceTraceRequired = true`
- `runtimeKlineContextRequired = true`
- `recheckRequired = true`
- `riskActionGuardRequired = true`
- `reviewOnly = true`
- `notTradeInstruction = true`
- `manualReviewRequired = true`

## Allowed Review-Only Output

P309 may output:

- review-only point proposal status
- incomplete / blocked / fail-closed status
- point proposal unavailable reason
- source trace required reason
- runtime kline context required reason
- Risk Action Guard required reason
- manual review required

## Blocked Output

P309 must not output:

- executable readiness
- executable point
- executable entry / stop / TP / RR
- final direction
- long / short signal
- order intent
- execution intent
- external push message
- auto-trading action

## User Value

P309 lets the point boundary gate advance into a source-owned, review-only point proposal object. It makes the future point proposal shape visible while preserving incomplete-safe behavior until the required source trace and runtime context exist.
