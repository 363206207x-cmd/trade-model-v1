# P333 SourceTrace Runtime / Source Binding Plan

## Purpose / 目的

P333 is a docs-only skeleton package for the future SourceTrace Runtime / Source Binding Plan.

P333 是未来 SourceTrace 运行时 / 来源绑定方案的 docs-only 骨架包。

P333 follows P332 `SOURCETRACE_NUMERIC_SOURCE_ASSEMBLER_VERIFICATION`, which verified the P331 assembler as an explicit-input SourceTrace read-model assembler only.

P333 承接 P332 `SOURCETRACE_NUMERIC_SOURCE_ASSEMBLER_VERIFICATION`。P332 已验证 P331 组装器只做显式输入的 SourceTrace 读模型搬运。

P333 defines the maximum safe planning boundary for future source binding without touching runtime wiring.

P333 只定义未来来源绑定的最大安全方案边界，不触碰任何运行链路。

## Capability Movement / 能力层级变化

`SOURCETRACE_NUMERIC_SOURCE_ASSEMBLER_VERIFICATION -> SOURCE_TRACE_RUNTIME_BINDING_PLAN`

This movement is governance / contract progress only.

该能力移动只属于治理 / 合同进度。

P333 does not raise Production Runtime Progress.

P333 不提高 Production Runtime Progress。

P333 does not mean real SourceTrace runtime read is complete.

P333 不代表真实 SourceTrace runtime read 已完成。

## Source Binding Boundary / 来源绑定边界

Future source binding may only plan how validated SourceTrace read-model outputs could be associated with pre-existing upstream evidence.

未来来源绑定只能规划如何把已校验的 SourceTrace 读模型输出关联到已存在的上游证据。

Source binding must preserve the current chain:

- `SourceTraceNumericSourceContextDTO`;
- `SourceTraceNumericSourceReadModelValidator`;
- `SourceTraceNumericSourceReadModelAssembler`;
- docs-only P332 verification;
- future docs-only P333 binding boundary.

来源绑定必须保留当前链路：

- `SourceTraceNumericSourceContextDTO`；
- `SourceTraceNumericSourceReadModelValidator`；
- `SourceTraceNumericSourceReadModelAssembler`；
- P332 docs-only 验证收口；
- P333 未来来源绑定边界。

SourceTrace remains a source identity. It is not a point calculator, signal engine, runtime reader, trading decision, or execution path.

SourceTrace 仍只是来源身份，不是点位计算器、信号引擎、运行读取器、交易决策或执行路径。

- `sourceRef`;

## Incomplete-safe Rules / 不完整安全规则

The future binding must remain `INCOMPLETE` when:

- any required ref is missing;
- `freshnessStatus` is `STALE` or `UNKNOWN`;
- source / symbol / market / timeframe does not match;
- RuntimeKlineContext is not connected;
- DataQualityContext is not connected;
- MultiTimeframeContext is not connected;
- RiskActionGuardContext is not connected;
- WatchlistPoolProof is missing;
- only latest price exists;
- only latest close exists;
- only dashboard text exists;
- only score / label / AI prose exists;
- source conflict is unresolved;
- `missingReason` is absent for unavailable source binding.

未来绑定在以下情况必须保持 `INCOMPLETE`：

- 任一必需引用缺失；
- `freshnessStatus` 为 `STALE` 或 `UNKNOWN`；
- source / symbol / market / timeframe 不匹配；
- RuntimeKlineContext 未接入；
- DataQualityContext 未接入；
- MultiTimeframeContext 未接入；
- RiskActionGuardContext 未接入；
- WatchlistPoolProof 缺失；
- 只有 latest price；
- 只有 latest close；
- 只有 dashboard text；
- 只有 score / label / AI 文案；
- source conflict 未解决；
- 来源绑定不可用但缺少 `missingReason`。

## Fail-closed Rules / 安全关闭规则

The future binding must remain `BLOCKED_FAIL_CLOSED` when:

- source is forged;
- source is untrusted;
- forbidden source type is used as evidence;
- source binding attempts to bypass the validator;
- source binding attempts to bypass Risk Action Guard;
- source binding attempts to bypass RuntimeKlineContext, DataQualityContext, or MultiTimeframeContext;
- executable semantics appear in source binding output;
- source binding implies entry / stop / TP / RR can be executed;
- source binding implies final direction;
- external channel is attempted;
- push send is attempted;
- order intent is attempted;
- execution intent is attempted;
- auto-trading is attempted.

未来绑定在以下情况必须保持 `BLOCKED_FAIL_CLOSED`：

- source forged；
- source untrusted；
- forbidden source type 被当作证据；
- 来源绑定试图绕过 validator；
- 来源绑定试图绕过 Risk Action Guard；
- 来源绑定试图绕过 RuntimeKlineContext、DataQualityContext 或 MultiTimeframeContext；
- 来源绑定输出出现可执行交易语义；
- 来源绑定暗示 entry / stop / TP / RR 可执行；
- 来源绑定暗示 final direction；
- 试图接外部通道；
- 试图 Push send；
- 试图产生 order intent；
- 试图产生 execution intent；
- 试图 auto-trading。
