It verifies the P345 DTO, P346 Validator, and P349 Assembler stages for Source-Owned Candidate Integration Source Binding.

## Fail-Closed And Incomplete-Safe Conclusion

Candidate integration must remain incomplete-safe or fail-closed.

It must return `BLOCKED_FAIL_CLOSED` when:

- any upstream source binding is untrusted;
- any upstream safety flag is disabled;
- RiskActionGuard is blocked;
- RiskActionGuard reports stampede;
- RiskActionGuard carries wick-only reverse semantics;
- RiskActionGuard carries liquidity-degraded one-shot exit semantics;
- WatchlistPoolProof is disabled;
- WatchlistPoolProof is empty;
- WatchlistPoolProof is non-member;
- WatchlistPoolProof is untrusted;
- executable semantics appear in candidate integration fields.

It must return `INCOMPLETE` or `BLOCKED_FAIL_CLOSED` when WatchlistPoolProof is stale, and it must never silently pass stale proof.

Display Slots and the default home six assets are not Watchlist Pool Proof.

Assembler behavior remains constrained:

- it must not skip the Validator;
- it must not promote incomplete or degraded input into review-only success;
- it must not modify a DTO after validator failure to make it pass;
- it must not drop validation reasons.
